最終定理、一般接続定理、証明の依存順序

1. 最終定理を整数だけで記述する

Grid(n)=Fin(n)×Fin(n)。各座標を整数へ埋め込んで
  det(p,q,r)=(q_x-p_x)(r_y-p_y)-(q_y-p_y)(r_x-p_x)
と定義する。
NoThree(S) は、Sの相異なる任意の三点p,q,rについてdet(p,q,r)≠0という命題。
最終定理Tは
  ∃n0∈N, ∀n∈N, n>=n0 ⇒
    ∃S⊂Grid(n), NoThree(S) ∧ 1501*n<=1000*|S|。
epsilon=1/1000は固定で、nに依存しない。n0>=2としてよい。
この定式化に床関数・浮動小数点・具体的なn0の算出は必要ない。

Lean試作ではこの命題をTargetとして定義する。Targetを証明済みとする宣言や、
Targetを仮定するaxiomは置かない。

2. 入力スケジュールの定義を一つに固定する

型集合は(Fin2)^2。整数点の型は座標ごとのmod2。
時刻分割0=t0<t1<...<tJ=T、全継続時間と空間端点は有理数で固定する。
共通空間格子の全直線の集合をBoundaryとする。
各phase j、型rの有限個のaccepted閉矩形とその対称像のunionをU_(j,r)とし、
  E_(j,r)=interior(U_(j,r)) \ Boundary,
  f_(r,t)(x)=1_{E_(j,r)}(x)   (t_(j-1)<=t<t_j)
と定義する。最終時刻の値は0としてよい。正方形の外でも0とする。
一般定理ではセルごとの有理値0<=f<=1も許せるが、今回の具体データは指示関数で足りる。
interior(union)と、さらに全共通格子線を除く操作を混同しない。
この除去は実際の格子点での出生率を定義し、単に面積0だから忘れる操作ではない。

F_(r,t)(x)=∫_0^t f_(r,u)(x)du、tau_r(x)はその位置・型の最後の使用区間の右端。
未使用ならtau=0。四型の場を評価するときは全て主根の同じtau_r(x)を使う。
A=(1/4)Σ_r∫ F_(r,T)。共線対risk、指定線capacityはgeometry稿の定義を使う。

3. 一般接続定理の契約

上記の有限スケジュール、固定有限Γ、および
  0<K<2, 0<rho<1, 0<=lambda<1-rho, 0<delta<1
をnより先に固定する。
ある固定正数κ_H,κ_L,κ_R>0が存在し、必要な全根・型・方向で
  指定capacity <= K-κ_H,
  指定外capacity <= lambda-κ_L,
  使用位置でのrisk(F_(tau_r(x))) <= delta-κ_R
とする。

結論は、各nに三点共線のないランダム集合S_nを構成でき、
  0<=|S_n|<=2n,
  ∀η>0, ∃n_η, ∀n>=n_η,
      E|S_n| >= (A-η)n
となること。
この結論を『接続仮定』として最終証明へ持ち込むだけでは完了ではない。
stochastic稿の各補題とgeometry稿から導出する対象そのものである。

4. 依存順序と循環を避ける境界

G：決定論幾何
  原始方向・格子線の計数 → 二星/固定線核 → 偶奇方向和とBV
  → 一様共線対risk、同一期限の時間対称化、capacity/面積Riemann和。

S0：補償過程と停止した法則

  → 固定ラベル全集合のη補正 → 混合source三角帰納 → 点の法則。
  この段階では全体停止が稀であることを仮定しない。

S1：補助停止の除去
  S0の混合量 + Gの二核 → η停止/仮想削除停止の高moment尾部。
  保存信用のentropy・保護線法則 → 指定線時計の集中。
  決定論capacityの余裕 → 時計停止確率の消去。
  cap/tagの早期引退が小さいことを、時計集中の前提にしない。

S2：点の法則でのriskと早期引退

  長線の葉量・証人代理量 + 短線星の全例外分類
  → 同一期限の決定論共線対和 + o(log n)というmoment評価。
  Gの主係数 + risk余裕 → 上限引退の点法則確率o(1)。
  固定線/固定maskの最大moment + 指定外capacity余裕 → tag確率o(1)。
  S1 + これらの点法則確率 → 保存された早期引退信用の期待総和o(n²)。

S3：点数
  保存信用E Z_p=1 − 早期引退信用 → 積分出生数E|S_n|。
  Gの面積Riemann和 → 一般接続定理の結論。

  有限参照場・accepted union・phase prefix → 幾何上界と容量、正確な質量。
  s=249/250の入力変換 → 新定数の余裕とA'>1501/1000。
  Cと一般接続定理を最後に合成する。
  データのSHAや保存上界の有理比較は、Cの幾何健全性の代用ではない。

1. 一般の時間短縮補題

有限個の有理な時間境界 0=t0<t1<...<tJ=T と、各区間の四型マスク f_{r,j} を取る。
0≤f_{r,j}≤1、空間上は固定された有限有理分割で一定とし、共通境界で0とする。
F_{r,t}(x)=∫_0^t f_{r,u}(x)du、最後の使用時刻を τ_r(x) とする。
未使用の型・位置では τ_r(x)=0 とする。

任意の有理数 0<s≤1 について、新境界 t'_j=s t_j、T'=sT とし
  f'_{r,t}(x)=f_{r,t/s}(x),  0≤t≤T'
を定義する。時間の端点での値は積分を変えない一貫した規約で定める。
マスク値自体を s 倍していないので、各段階の採用領域は以前と同じである。
有限有理性、0≤f'≤1、空間境界上0、分割の n からの独立性を保つ。

変数変換 u=sv から、全ての r,x,t について
  F'_{r,t}(x)=s F_{r,t/s}(x)。                                  (1)
有限個の使用段階の最後の端点も同じ順序で移るため
  τ'_r(x)=s τ_r(x)。                                           (2)
未使用の場合にも (2) は成立する。

非負場の主座標弦積分 C_d は線形である。従って終端の方向容量は
  L_{d,r}(F'_{T'};x)=s L_{d,r}(F_T;x)。                         (3)
g_H は弦積分の二乗を方向について平均した量なので g_{sH}=s²g_H。
全型を同じ時刻 t/s で評価する (1) と (2) により
  R_r(F'_{τ'_r(x)};x)=s²R_r(F_{τ_r(x)};x)。                    (4)
最後の使用時刻を型ごとに誤って独立に入れ替える操作はしていない。
終端の平均質量と時間は
  A'=sA,  T'=sT。                                             (5)

これは決定論的入力の補題である。新しい確率過程が旧過程の同じ標本路を
時間変更したものだとは主張しない。新しい上限指数や信用床を用いる場合も、
変更後の入力に対して一般接続定理を適用し直す必要がある。

3. 既存上界を再利用できる数学的理由

各段階の実累積場は対応する参照場以下である。この支配関係は (1) で保たれる。
各閉葉 Q に保存された U(Q) が、元参照場について
  Σ_{a≠r}g_{F_r+F_a}(x)≤U(Q)  (x∈Q)
を満たすなら、新参照場に対する上界は s²U(Q) である。

上界を継承するのではない。対称像の適用と union 面積も変わらない。

4. 最終目標の整数表示

目標は、ある n0 が存在し、全ての n≥n0 に対して
  S⊂{0,...,n−1}²、どの三点も共線でなく、1501 n≤1000 |S|
を満たす S が存在することとする。ε=1/1000 は明示された固定値である。

一般接続定理が E|S_T|=(A'−o(1))n を与えるなら、(6) より十分大きい n で
E|S_T|>c n。出力は有限集合の部分集合を値に持つので、全出力の点数が c n 未満
という仮定はこの期待値と両立しない。合法な出力の中に |S|≥c n が存在する。
整数不等式 1501 n≤1000|S| へ直せば床関数は不要である。

元の接続を「全ての固定 b<A' に対し floor(bn) 点」の形で使う場合は
b=(A'+c)/2 を選ぶ。n≥1/(b−c) なら floor(bn)≥bn−1≥cn となる。
この床誤差の閾値と、確率論から来る未知の十分大きさの閾値の最大を取ればよい。
これにより具体的な全体 n0 が得られたとは主張しない。

有限和を積分し、指示関数の積の積分を区間交差の長さへ直すと(C5)が得られる。
明らかにU2≥0。証明終。

補足：頂点係数から水平jumpを復元できる。固定ηで
  κ_{a,η}=J_left−J_right
なので、左端のJ=0から順にJ←J−κと更新すれば全水平辺のjumpを得る。
右端でも0へ戻ることは有限支えから従う。これは現実装make_edgesの式に対応する。

4. 最小上界の健全性と可積分性 [C04]

  U(u)=min(U1(u),U2(u),M)   (u>0)
とする。(C0),(C4),(C5)から、全(x,y)∈Qとv=y−uxについて
  0≤C(v;u)≤U(u)≤M。                                      (C6)
従ってC(v;u)²≤U(u)²。各Uは有限の連続関数のmax/min等から作られ、(0,1]で可測。
u=0ではU(0)=Mと定めれば軸方向も(C0)で覆う。この単点の値は積分を変えない。
有界性から[0,1]上で可積分である。

点根Qの場合はU=C(l;u)とすれば同じ結論を得る。必要ならU=min(C(l;u),M)としても等しい。
辺だけの退化矩形もh−l>0なら(C2)以降がそのまま使える。

5. 有理区間の枝検査へ落とす [C05]

全座標・密度が有理数なので、(C4),(C5)に現れる基本式は全てα+β/uの形である。
例えば
  (v_l−η+ua)_+/u=[(a−a1)+(b0−η)/u]_+,
  (v_h−η+ua)_+/u=[(a−a0)+(b1−η)/u]_+,
  |[a,b]∩[(η−h)/u,(η−l)/u]|
   =[min(b,a1+(η−b0)/u)−max(a,a0+(η−b1)/u)]_+。
P,Qv,(P+Qv)/4もこの形である。従ってUの式は、有限の基本式、加算、有理数倍、
max/min、正部分からなる有限の式木として表せる。

正の有理区間[r,s]上で二式A=α+β/u、B=α'+β'/uを比較する。
u>0を掛ければ、A−Bの符号は一次式
  L(u)=(α−α')u+(β−β')
の符号である。L(r),L(s)が共に非負なら、u=(1−t)r+tsに対し
L(u)=(1−t)L(r)+tL(s)≥0。非正の場合も同じ。
従ってmax/minのどちらの枝が区間全体で有効かを、二つの有理端点比較で検証できる。
加算と有理数倍は係数を直接計算する。式木に関する帰納から、全枝検査が通れば
指定されたα+β/uは区間全体でUに等しいことが従う。

完全な有限分割は必ず存在する。基本式の二式の差は一次式/uであり、
非恒等的な交点は高々一つ、存在すれば有理数である。子の有限分割を共通細分し、
その各区間の二式の交点を足す操作を式木で有限回行えばよい。
恒等的な同値は交点を無限に作らず、片方を選ぶ。

検証器は分割探索器の正しさを仮定する必要はない。
  0=u0<u1<...<uJ=1
の順序・被覆と、各正区間の全枝条件を確かめればよい。
最初の区間(0,u1]でも一次式の端点u=0,u1による比較は有効である。
ただし最終積分のために、最初のUのβ=0を確認する。
有限分割と(C6)が成立すれば、β≠0はu→0でUが無限大または負となるので不可能である。

別の安全な方式として、最初の区間に上界Mを使ってもよい。
一般にもUと厳密に等しい式ではなく、検証済みの上界V≥U≥Cを使える。
この場合はVの非負性と積分上界を同じ有限検査で保証する。強い上界を必ず選ぶ必要はなく、
弱すぎる上界なら最終閾値を通らず不採用になるだけである。

6. 対数の有限級数と剰余 [C06]

0<r<sを有理数とし、z=(s−r)/(s+r)と置く。0<z<1で、s/r=(1+z)/(1−z)。
任意の整数m≥0について有限等比恒等式
  1/(1−t²)=Σ_{j=0}^{m−1}t^(2j)+t^(2m)/(1−t²)
を0≤t≤zで積分する。
log((1+t)/(1−t))の微分は2/(1−t²)、t=0で値0だから
  log(s/r)=2Σ_{j=0}^{m−1} z^(2j+1)/(2j+1)+R_m,
  R_m=2∫_0^z t^(2m)/(1−t²)dt。
分母について1−t²≥1−z²>0なので
  0≤R_m≤2 z^(2m+1)/[(2m+1)(1−z²)]。                       (C7)
これで下端L_-と上端L_+が有限の有理式として得られる。
無限級数の項別積分を先に仮定する必要はない。r=sならlog=0を別に使えばよい。

数値実装でs/rが大きい場合は、あるk≥0とq∈[1,2]によりs/r=2^k qと分ける。
  log(s/r)=k log2+log q
に(C7)を使えばよい。この分解は2を順に掛ける有限整数比較で検証できる。
q≤2ならz≤1/3なので短い級数でも囲いは狭くなるが、狭さは健全性の条件ではない。
任意の有限mについて(C7)は成立し、広すぎれば採用判定が失敗するだけである。

7. 一区間の二乗積分と外向き算術 [C07]

0<r<s上でV(u)=a+b/uとする。通常の原始関数から
  I(a,b;r,s)=∫_r^s V(u)²du
   =a²(s−r)+2ab log(s/r)+b²(1/r−1/s)。                     (C8)
基底項B0=a²(s−r)+b²(1/r−1/s)は有理数である。
(C7)のL_-≤log(s/r)≤L_+とc=2abを用いれば、
  c≥0: B0+cL_- ≤ I ≤ B0+cL_+,
  c<0: B0+cL_+ ≤ I ≤ B0+cL_-。
係数の符号が負のときに上下を交換することが不可欠である。
最初の区間[0,s]はb=0なのでI=a²s。特異な1/u式を0に代入しない。

固定点区間算術を使う場合も健全性は直接示せる。
整数l≤hが[l/S,h/S]を表すものとする（S>0整数）。正分母の有理数p/qは
[floor(pS/q),ceil(pS/q)]で囲える。加算・減算はそれぞれ
[l1+l2,h1+h2]、[l1−h2,h1−l2]。
積は四つの端点積の最小・最大を取り、それぞれSで割ってfloor/ceilする。
区間上の双一次式の極値が四端点で達成されるため、符号にかかわらず積を囲う。
正整数での除算もfloor/ceilで囲える。有限の計算式への帰納で包含性が保たれる。
演算に有限幅整数を用いる実装では、オーバーフローした結果を受理してはいけない。
Lean側は任意精度整数を用いるか、有限幅演算と数学的整数の一致を別に証明する。

現logshortの剰余計算とも対応する。z²の区間上端をz2_hi/S、
z^(2m+1)の上端をpower_hi/Sとし、z2_hi<Sなら、(C7)の剰余上端の整数表現には
  ceil[2 power_hi S / ((2m+1)(S−z2_hi))]
を使える。非負の剰余を下端へ足さず上端だけへ足す。
途中で項数を短縮しても、使ったmと残るpowerが一致すれば同じ証明が適用される。

8. 一方向・全方向・型リスクの合成 [C08]

有理分割の各区間に(C07)の上端I_j^+があり、各V_jが閉根矩形全体の弦を覆うとする。
区間境界の有限個の角度は積分を変えず、非負性から
  ∫_0^1 c_F(x,u)²du ≤ Σ_j I_j^+    (全x∈Q)。              (C9)
根xによらない右辺なので、根についての積分や平均を使う必要はない。

四方向族は次の正方形の対称変換により同じ(1,u)の補題へ戻る。
  (1,u): 恒等、
  (1,−u): (x,y)↦(1−x,y)、
  (u,1): (x,y)↦(y,x)、
  (−u,1): (x,y)↦(1−y,x)。
場は逆変換で移し、根矩形は同じ変換で移す。方向の符号反転は積分変数の向きを変えるだけ。
主座標の変数変換の絶対値は1であり、余分な角度Jacobianや長さ係数は生じない。
従って四方向の上端をI_1^+,...,I_4^+とすれば
  g_F(x)≤(I_1^++...+I_4^+)/4    (全x∈Q)。                 (C10)

対称像への再利用も区別する。座標交換T(x,y)=(y,x)と中心反転R(x,y)=(1−x,1−y)は
四方向族を、符号反転を除いて置換する。主座標パラメータの絶対値は変わらないので
  g_F(Tx)=g_{F∘T}(x)、g_F(Rx)=g_{F∘R}(x)。
従ってFがその変換に不変である場合に限り、代表Qの同じ上界をTQ,RQへそのまま再利用できる。
非対称な場では、変換した場を計算するか各像を別に認証する必要がある。

型rの各s≠rに対して、非負場F_r+F_sに(C10)を適用し、得た有理上端をG^+_{r,s,Q}とする。
D>0なら
  R_r(F;x)=(D/6)Σ_{s≠r}g_{F_r+F_s}(x)
           ≤(D/6)Σ_{s≠r}G^+_{r,s,Q}。                    (C11)
右辺をδより小さいと有理数で検査すれば、閉根矩形全体のrisk条件が従う。
時間縮小s0=249/250を最後に適用する場合は、右辺全体をs0²倍すればよい。
ここでDは任意に小さく選べる係数ではなく、一般接続に必要な固定D>D0である。

2026-11-08

範囲

この補足は『標準的なPDMP定理による』という一括した呼出しを分解する。
固定nで有限本の有界率の候補時計、有限次元の停止ODE、有限個の幾何更新だけを使う。

P0. 事前状態、停止を起こす出生、積分の端点

候補時刻の出生判定は、その時刻の幾何更新前の状態で行う。
その出生が全体停止を引き起こしても、出生と幾何死亡を処理してから停止する。
従って停止した出生数はN_(t∧sigma_global)であり、停止を引き起こす出生を含む。
予測可能な表示では、停止前の強度を1_{t<=sigma_global}で切る。
dt積分では1_{t<sigma_global}を使っても同じ値である。
各経路で異なるのは高々一時刻だからであり、最後の出生を消すという意味ではない。
同様に正引退境界での混合量は、幾何更新後・正引退フラグ変更前のsnapshotを保存する。
guardが起きなければsigma_global=∞。自然な終端Tそのものを失敗guardに含めない。
主根の観測停止はTとの最小を取り、有界な停止時刻にする。

P1. 有限支配時計による構成

固定n>=2ではlambda_p<=B/n、候補点はn²個なので総率はnB以下。
各点に率B/nの独立Poisson候補時計と、各到来に独立な[0,1]一様markを付ける。
これらは可算個の独立指数待ち時間と一様変数の積確率空間から構成できる。
指数待ち時間の部分和が∞へ行くことから固定T内の到来数は有限で、
その期待総数はnBTである。各時計の独立増分とmarkの一様性を用いる。
無限個の空間点に時計を付ける構成は不要。

filtrationは、各時刻までの候補到来と、その時刻までに現れたmarkが生成する自然filtrationの
完備化・右連続化とする。積空間に保存された未来の待ち時間やmarkを事前に公開しない。
異なる候補時計の同時到来は確率0。必要ならその零集合上にも固定の点順で処理規約を定める。

候補到来の間は、選択済集合、活性・引退フラグ、線占有数、phase等の離散modeを固定して
ODEを解く。w,k,r,etaは有限次元であり、guardを処理する前の閉領域では
  0<=w<=B、0<=k<=K<2、rho<=r<=1、1-n^(-zeta)<=eta<=1
を持つ。固定n>=2で最後の下限も正である。死点・凍結成分には微分0を与える。
右辺は有限の和・積・正の分母を持つ商であり、そのmodeの領域の近傍で局所Lipschitz。
連続重みにはlog wではなくwを座標として用い、死点w=0で未定義なlogをODEへ入れない。
wの流れはw'=w Aの形なので非負性を保ち、rとetaは非負率の指数減衰、kは非減少である。
従って記載した上限・床のguardと幾何更新を処理すれば、この領域から未検出で退出しない。

存在と可測性の適用条件は次のように閉じる。停止領域を少し広げたコンパクト近傍を取り、
分母を正に保ち、座標のcutoffを外側へ付ければ、元の領域上で一致する有界で大域Lipschitzな
ベクトル場へ延長できる。有限個のmodeごとに行い、固定nではLipschitz定数の有限最大を取れる。
Picard–Lindelöfにより延長場の一意なflow phi(t,z)が存在し、Gronwallの評価
  |phi(t,z)-phi(t,z')|<=exp(L_n t)|z-z'|
から初期値・時間への連続依存を得る。実過程は最初のguardまでしかこの延長を使わないので、
領域の外側での延長の選択は実際の経路を変えない。

固定modeのguardは、有限和・有限最大・閉不等式で定義される閉集合Gである。
空guardなら到達時間を∞とする。非空なら、固定a>=0について
  z -> min_(0<=s<=a) dist(phi(s,z),G)
は連続で、最小値0と『aまでに閉guardへ到達』が同値である。
従って初到達時間h(z)の集合{h<=a}はBorel。開始停止時刻UとF_U可測な状態z_Uから
U+h(z_U)へ進む時刻も停止時刻となる。実際、h(z_U)はF_U可測かつ非負であり、
{U+h(z_U)<=t}は{U<=t}上のF_U可測事象だからF_tに属する。
phase境界・締切も時間座標を加えた閉guardとして、または既知の有限時刻として扱える。

次の更新時刻は、このflow到達時刻、次の候補到来、次のphase時刻の最小である。
出生判定、幾何更新、境界snapshot、処理済フラグの変更は有限のBorel操作なので、
停止時刻ごとの帰納で更新状態は過去の情報へ適応的となる。
同時の境界はP0の優先順位で一括処理し、処理済guardを再び時刻0の更新として数えない。
cap/tag/締切による正引退は各点一回、補助線の初回タグ等も有限本につき各一回、
全体停止は一回、phase切替は固定有限回。候補到来もTまでに有限なのでZeno更新は起こらない。
未受理候補では状態を変えない。更新後の値を採用することで状態はcadlagとなり、
左極限X_(t-)は予測可能である。有限更新の切詰め構成の極限でも同じ可測過程を得られる。

P2. thinningと補償恒等式

候補pの到来を、事前状態X_(t-)から計算した
  a_p(t)=1_{t<=sigma_global} 1_{pが事前状態で出生可能} m_t(p)w_p(t-)/B
以下のmarkのとき受理する。全体停止後と出生不能点ではa_p=0である。
0<=a_p<=1で、受理強度は(B/n)a_p=lambda_pとなる。
m_tは既知のBorel時間関数。X_(t-)は予測可能、1_{t<=sigma_global}は左連続な適応過程なので
予測可能であり、a_pも予測可能である。受理判定に出生後のw_p(t)を使ってはいけない。
dt積分だけではt<sigmaと書き換えられるが、停止を引き起こす到来の受理判定では
t<=sigmaの事前状態規約を保つ。

基本恒等式は、予測可能な有界観測g_pについて
  E Σ_{受理出生(p,t),t<=T}g_p(t)
       = E ∫_0^T Σ_p lambda_p(t)g_p(t)dt。               (P2.1)
まずgとaが有限の時間区間の左端までの情報で決まる単純関数なら、
候補時計の独立増分と一様markを条件付き期待して直接得られる。
有界予測可能関数へは単純関数近似と単調類/支配収束で拡張する。
非負関数では単調収束、符号付き有界関数では正負に分ける。
候補到来数の期待nBTが有限なので、有限和側の可積分性が保証される。
同じ恒等式を時刻sの事象Aに制限して使うと、補償した和の増分の条件付き期待は0となる。

状態の有界観測Phiが、各離散状態の流れの上でC1、各出生branchで定義され、
流れ微分と出生後の差が固定nで有界とする。出生の幾何更新による差をDelta_p Phiとし、
正引退・phase切替など、それ以外の境界更新による差の累積をJ_bd(t)と書く。
同じ出生時刻に正引退も起こる場合、P0のsnapshotまでを出生差、その後のフラグ処理を
境界差として一度ずつ数える。経路ごとの有限回の更新を足して
  Phi(t)-Phi(0)
    =∫_0^t D Phi(flow) ds + Σ_{出生時s<=t}Delta Phi(s)+J_bd(t)
となる。正引退時に観測値を保存する場合、その境界差は0。
補助根の正引退で観測を0へ落とす場合は、その境界差は非正である。
phase切替では係数mだけが変わり観測値が連続、という条件も確認する。
一般の観測に正の境界差があれば省略してはいけない。
P2.1を使って
  M_t=Phi(t)-Phi(0)-J_bd(t)-∫_0^t[ D Phi +Σ_p lambda_p Delta_p Phi ]ds
はmartingaleになる。J_bd=0の場合はこれが通常の補償観測であり、
J_bdが非増加ならJ_bdを残した観測はsupermartingaleとなる。
この式が第一稿のgenerator計算を実際の期待値・条件付き期待へ渡す箇所である。
既に有界な停止領域にあるため、局所martingaleを可積分性未確認のまま使っていない。
境界差の総変動も固定nで有限個の有界更新から抑えられる。

P3. 有界停止と密度による点の法則

有界martingale Z、0<=Z<=B、EZ_0=1について、
  P^Z(A)=E[Z_T 1_A]
は確率測度である。F_tへの密度はE[Z_T|F_t]=Z_t。
従ってF_t可測な非負XについてE^Z X=E[Z_t X]。
有界停止時刻tauでもE[Z_T|F_tau]=Z_tauを使えば同じ式が成り立つ。

この有界停止版は、tauを上から近似する有限dyadic値の停止時刻tau_kで示した
離散停止定理から得られる。Zの右連続性でZ_(tau_k)→Z_tau、|Z_(tau_k)|<=Bによる
支配収束を用い、A∈F_tau⊂F_(tau_k)上の積分等式を極限へ渡す。
Tを越えた近似値に備え、過程をT以後一定に延長しておけばよい。
今回の信用は連続flowと有限jumpを繋いだ右連続過程なので、この仮定を満たす。

主根が出生qでJ_p(q)倍となる境界前には、P^Z下の出生率はJ_p(q)lambda_q。
これを仮定にせずP2.1から導くには、出生観測に対するZ_Tを出生直後のZ_tへ条件付け、
Z_t=J_p(q)Z_(t-)を代入してからP2.1を適用する。
具体的には出生時刻を列挙し、各時刻とTの最小に有界停止版を使う。
観測停止までに支えを持つ非負の予測可能g（1_{t<=tau_obs}を含める）について
Tonelliで和と期待を交換すると
  E^Z Σ_birth g = E Σ_birth Z_t g
                 = E ∫ Σ_q Z_(t-) J_p(q)lambda_q g dt。
右辺をF_tへの密度で書き戻すとE^Z∫Σ_q J_p(q)lambda_q g dtとなる。
dt積分側ではZ_(t-)=Z_tがほとんど全てのtで一致する。
条件付きBayes公式でZ_sを割るのはZ_s>0上だけ。Z_s=0の集合はP^Z-nullである。
全体停止・主根正引退後には観測全体を保存し、後から出生源を追加しない。
上の強度式はその観測停止までに限定する。凍結後の出生を同じJ_pで新たに数えない。

P4. 保護線の密度

指定線ellの一占有段階を固定し、その開始停止時刻をUとする。
その段階がTまでに開始しない経路ではU=Tとして以後の密度を1とする。
Uより前はD=1、U以後はその段階での次の線上出生がない指示関数と、
Uからの積分の積
  D_t=1_{(U,t]にその段階の線上出生なし} exp(∫_U^t Lambda_ell ds)
を、global guard・時計guard・終端Tで停止して保存する。
Uの出生自体は新段階の次の出生へ重複計上しない。
連続driftはD Lambda、次の線上出生ではDが0になるので、その補償driftは-D Lambda。
P2よりmartingale。時計停止まで∫Lambda<=2log A0なので0<=D<=A0²。
積分上界はLambda dt=a_N(k)dkとa_N(k)<={2/(2-k)}を積分したもので、
段階開始のk(U)がどこでも∫Lambda<=∫_0^K 2/(2-k)dk=2log A0である。
従ってE[D_T|F_U]=1で、P3と同様に開始履歴を条件とした確率の重み付けを定義する。
線上出生の倍率は0、他の出生は1だから、前者の率だけが0になる。
外部出生の率や、元の状態ODEまで勝手に消すことはしない。
占有1の段階では開始履歴を条件に同じ議論を行う。上界A0²は履歴によらないので、
条件付き上界を平均すればよく、開始時刻や履歴の個数をunionに数える必要はない。

P5. 同時jumpを含む予測二乗変動

P2で境界差J_bdを除いた補償martingaleをY=Mと書く。
各出生のjumpをa_p=Delta_p Phiとすると、
  Y_t=Σ_{出生(p,s),s<=t}a_p(s)−∫_0^tΣ_p lambda_p(s)a_p(s)ds。
従って出生間の連続部分は補償driftであり、別の連続martingale成分はない。
各点は一度しか出生しないので出生数はn²以下。aと総率が固定nで有界であるため
Yと以下のQは固定n,Tで有界となり、二乗の可積分性も確保できる。
  Q_t=∫_0^t Σ_p lambda_p(s)(Delta_p Phi(s))² ds
は連続・適応的・非減少で予測可能。Y²の流れ微分は-2YΣlambda a、出生差は
2Y_(t-)a+a²なので、P2を適用すると一次項が相殺され、Y²-Qがmartingaleとなる。
従ってQは予測二乗変動である。
一出生が多数の点を同時に変更する場合、Delta_p Phiはその総変化である。
各点の二乗の和に置き換えてcross termを落としてはいけない。
時計entropy稿のDelta²<=max(Delta)*Deltaは、総変化の二乗を評価するために使う。

P6. 有界jumpの指数最大不等式

P5の表現を持つYについて、Y_0=0、|a_p|<=b、x,v,b>0とする。
0<theta b<3とし、|u|<=bに対するTaylor級数の項別評価から
  exp(theta u)-1-theta u
       <=theta²u²/[2(1-theta b/3)]
を得る。係数評価にはk!>=2*3^(k-2) (k>=2)を使う。
負のuでも絶対値を使って高次項を上から払えば同じ不等式となる。
psi=theta²/[2(1-theta b/3)]とする。

未停止の指数観測へ有界観測用のP2をそのまま適用する必要はない。
tau_x=inf{t>=0:Y_t>=x}、tau=tau_x∧Tとし、先にこの時刻で過程を停止する。
これは通常のfiltrationで停止時刻であり、今回の有限flow/jump構成では、Yを状態へ加えた
閉guard Y>=xの初到達としてP1でも扱える。
Yの右連続性からtau_x<=TのときY_(tau_x)>=x。停止前にはY<x、連続到達なら値x、
停止jumpならY_tau<=x+bなので、全時刻で
  0<=X_t=exp(theta Y_(t∧tau)-psi Q_(t∧tau))<=exp(theta(x+b))。
またQ>=0。出生差と流れ微分も、この上界、|a|<=b、総率<=nBにより固定nで有界である。

出生前の連続driftと出生jumpをP2で合わせると、Xの補償driftは
  X_(t-) Σ_p lambda_p(t)
      [ exp(theta a_p)-1-theta a_p-psi a_p² ]
であり、上のTaylor評価により非正となる。停止を引き起こす出生もP0通り含める。
従ってこの停止済みの有界Xはsupermartingaleで、E X_T<=X_0=1。
有界性を未確認の指数local martingaleに期待値1を仮定していない。

Q側では停止しなくてよい。Qが連続非減少なので
  {∃t<=T:Y_t>=x,Q_t<=v}
    ={tau_x<=T,Q_(tau_x)<=v}。
右辺の事象ではX_T>=exp(theta x-psi v)。これでQ=vの境界の成功も含まれ、
『vを越える初時刻』で早く止めて成功を落とす問題を避けられる。
従って
  P(∃t<=T:Y_t>=x,Q_t<=v)<=exp(-theta x+psi v)。
v>0に対しtheta=x/(v+bx/3)を選んで
  P(∃t<=T:Y_t>=x,Q_t<=v)
       <=exp[-x²/(2(v+bx/3))]。
今回の時計評価はx,v,b>0のこの場合だけを使う。
費用Vによる追加停止も、先に有界停止した同じ法則の中で行う。

1. 固定データと、有限集合上の幾何

各点を通る指定線は各方向につき高々一本。

時刻区間[0,T]を有限個の区間へ分け、各点pに決定論的マスクm_t(p)∈[0,1]を置く。
区間内部ではtに一定、各切替時刻では右連続の値を使う。
型別有理セルのマスク m_t(p)=f_{sigma(p),t}(p/n) はこの特別な場合である。
各pについて、最後に正のマスクを使う区間の右端をtau(p)とする。
一度も使わない点はtau(p)=0。必ず m_t(p)=0 for t>tau(p)。

定数 0<delta<gamma<1、0<K<2、0<rho<1、xi,zeta>0 を固定する。
B=n^delta。a_N(k)=(2−N)/(2−k)、N=0,1、b0=1/2、b1=1。

N=0ではa0>=1、N=1ではa1>=1/2である。

2. 状態変数と、正の引退の順序

Sは選択済み点、Qは生存・未選択・未引退点。初期S=空、Q=V_n、w_p=1。
各pには次の互いに素な状態を持たせる：active / selected / geometric-dead / positive-retired。
選択済み点はSに永久に残る。死亡点・引退点はQへ戻さない。
選択または死亡は信用を0にする。正の引退だけが直前の正値を保存する。

指定線ellには占有数N_ell=|S∩ell|と時計k_ellを持たせる。
指定外線には活性指示と信用r_ellを持たせる。占有0でr=1、最初の出生時もr=1。
占有1の間だけrを動かす。占有2以降のrは凍結する。

出生率・jump倍率J・出生源は、常にそのjumpの直前状態から計算する。
dt積分では右連続版と左極限版の相違は測度0なので同じ値となる。
全体停止時刻sigma_globalは、[0,T]内で指定guardが初めて成立する時刻のinfとし、
guardが成立しなければ+∞とする。物理終端Tそれ自体を全体停止guardに含めない。
従って「全体停止が起こる」事象はsigma_global<=Tであり、自明な事象ではない。
Qのsnapshotを停止後にも保存してよいが、
「出生可能」はt<sigma_globalかつp∈Qという条件である。
出生率はこの条件の下だけで
  lambda_p(t)=1_{t<sigma_global}1_{p∈Q_t}m_t(p)w_p(t)/n。
この表示はdt積分用である。停止を引き起こす最後の出生も(a)〜(d)で受理して出力に含める。
jump側は直前状態による停止count N_{t∧sigma_global}を使い、その予測可能強度は
1_{t<=sigma_global}1_{p∈Q_{t−}}m_t(p)w_p(t−)/n とする。
各経路で<と<=の相違は一時刻だけなので、dt積分は上の表示と一致する。
その他ではlambda_p=0。Lambda_ell=Σ_{p∈ell}lambda_p。
現在出生可能信用C_p(t)=1_{t<sigma_global}1_{p∈Q_t}w_p(t)と書けばlambda_p=m_t(p)C_p/n。
H_pとkappa_abも同じ停止済み率で定義し、全体停止後は0である。
以下のactive中のODE・generatorは停止前に限り、停止後は保存量を動かさない。
時計はN=0,1で dot k=Lambda/a_N(k)、N>=2で凍結。
指定外線はN=1で dot r=−r Lambda、それ以外でdot r=0。

一つの出生qは次の順序で処理する。
(a) qをSに加え、q自身の信用を0にする。
(b) 選択済み二点と共線になるactive点を全て幾何死亡、信用0にする。
(c) qが初回出生である指定線上の残存active点の重みを1/2にする。
    二本の異なる指定線を同時に通る同じ他点は存在しないので二重半減は起こらない。
(d) k,rの離散状態・活性指示を更新する。時計値とrの値自体に不連続な再初期化はない。
(e) 補助全体停止、正の引退の条件を処理する。
従って、幾何死亡と正の引退が同時なら必ず0が優先される。

出生間には、active pの重みを
  dot log w_p=H_p+lambda_p+
       Σ_{ell∋p, ell指定}(Lambda_ell−lambda_p)b_{N_ell},       (S1)
  H_p=Σ_{q∈Q\{p}}lambda_q
       1{p,qを通る指定外線が選択済み点を持つ}

3. 有限時間までの構成

4. 保存一点信用のmartingale

Z_pは、pがactiveの間はw_p、selected/deadなら0、正引退または全体停止ではその値を保存する。
保存済みの正信用をV_p(t)と書くと、全時刻で Z_p(t)=C_p(t)+V_p(t)。
V_pは自身の正引退または全体停止で一度だけ記録され、その後変えない。
0<=Z_p<=B。active pに対する原因qの跳躍倍率をJ_p(q)とする。
q=pならJ=0。q≠pで幾何死亡を作るならJ=0、指定線初回ならJ=1/2、それ以外J=1。
各qはpとの一つの線だけに関係するので
  dot w_p=w_p Σ_q lambda_q(1−J_p(q))。
これは(S1)の各項と一対一に対応する。

原因qのcompensatorによる跳躍driftはlambda_q w_p(J_p(q)−1)。
連続driftと足して0。正の引退・全体停止はZの値を変えず、それ以後のdriftも0。
幾何死亡と正引退が同時なら、既に上のJ=0が処理されている。
従ってZ_pは有界martingaleで
  E Z_p(t)=1、E[Z_p(t)|F_s]=Z_p(s) for 0<=s<=t<=T。         (S2)

指定線の連続変化は dot log a_N=Lambda b_N。
初回出生のa1/a0=1/2はwの半減と一致する。従ってactive中の厳密な積表示は
  w_p=exp{∫H_p+∫lambda_p(1−Σ_{ell∋p指定}b_{N_ell})}
              ·∏_{ell∋p指定}a_{N_ell}(k_ell)。              (S3)
自己補正の絶対値はmax(1,g−1)TB/n。
従ってnが十分大きければactive w_p>=2^{−g−1}、またw_p/a_N>=2^{−g−1}/A0。
いずれもnに依存しない正の下界である。

5. ラベル全集合を固定した混合量

互いに素な固定集合C,Dを取る。Cはactiveを要求する根、Dは出生済み証人。

無限個の実線を掛ける必要はなく、Cの二点以上を含む有限本だけでよい。

とする。両端activeの間dot eta_ab=−kappa_ab eta_ab、初期1。

重要：補正積は現在のCだけでなく固定全集合L上に取り、

未出生証人を物理根へ移した源も同じLを使うため、出生前後でeta積は同じである。

6. 外部出生のgeneratorを全て展開する

q∉Cを固定し、qを通る直線ごとにCを群分けする。群の大きさをmとする。
指定外活性線では各根の補償m lambda_qからr^{m−1}が(m−1)lambda_qを引き、
群の連続寄与はlambda_q、出生後群の倍率は0。

群の連続寄与はlambda_q/2。出生の倍率は
  (1/2)^m (a0/a1)^{m−1}=1/2。
指定線N=1では群の連続寄与lambda_q、出生倍率0。
指定外空線では連続寄与0、倍率1。
従って各群にはJ_i∈{0,1/2,1}が対応し、全相対generatorは
  lambda_q [Σ_i(1−J_i)+∏_iJ_i−1]。                       (S6)

d_i=1−J_iとすると、有限Bonferroni不等式
  0<=Σd_i−[1−∏(1−d_i)]<=Σ_{i<j}d_i d_j
が使える。右辺は、同時変更される異なる群を一組ずつ数えた値以下。
各群から一根ずつ取れば、異群の根対は必ずqを含む基線上にない。
従って(S6)の正部は lambda_q Σ_{{a,b}⊂C}1_{q基線外共同変更} 以下。

補正積は連続なので跳躍との交差項はない。

q∈Cの場合は源ではない。q自身の連続補償lambda_qが残り、
qと同線の他根の補償は同じ線の接続因子によって全て相殺される。
出生でq自身が0になるので跳躍driftは−lambda_q。和は0。
etaの連続補正はさらに非正なので、内部原因も正driftを作らない。
非主根の正引退は(S4)を0へ落とすだけであり、これも有利である。

7. 未出生証人からの正源価格

全ラベルのどの二点も指定線を共有しない一般配置なら積は1で、単位源価格が厳密に保たれる。

8. 三角帰納を積分式で閉じる

一般配置では beta_q(t)=m_t(q)e_q(t)/n、その他では beta_q(t)=max(1,A1)^g m_t(q)e_q(t)/n。

  U_C,D(t)<=Σ_{q∈D}∫_0^t beta_q(s)U_{C∪{q},D\{q}}(s)ds。

最後の等式は有限積の微分と初期値0による。独立性を仮定した式ではない。

Bayes公式の割り算はZ_p(s)>0上で行い、Z_p(s)=0の集合はP^(p)の零集合として除く。
主根境界後を0にする評価対象は、保存混合量より小さいため上界を増やさない。

5. 指定線の保護法則と保存信用の集中

指定線ellの占有段階N=0または1を固定し、次のell上出生を禁止する法則を使う。

後からa_Nの変化で保存値を割り直さない。

N=0ならlambda_pc_p/2、N=1なら0。
この式は(S1)からdot log a_N=Lambda b_Nを引き、禁止された自身の線上出生の
compensatorを除いた結果である。

一つの固定セル・型の部分集合Eについて、動くcと保存したcの和をM、
h(c)=c[1+log(2B/c)]、h(0)=0 の同じ保存和をHとする。

というmartingale分解を得る。

他の指定方向からの影響点は高々g人、各c<=2Bなので、同時変更の全減少量は

半減・死亡の費用は減少c(1−J)と固定定数倍で比較できる。
各点の二乗和へ置き換えず、イベント全体にDelta²<=(最大Delta)Deltaを使うことで
  <Y_M><=C n^gamma V、<Y_H><=C n^gamma(log n)² V。          (C7)

martingale最大不等式

6. 全体停止の確率と点法則への移送

7. 指定外線信用を外す誤差を、自己率まで含めて評価する

主根pの境界前だけを考え、I_p=∫_0^{sigma_p}1_{p∈Q_t}H_p(t)dt、tau=tau(p)とする。

指定外ell∋pの H_ell(t)=r_ell(t)Σ_{q∈ell\{p} active}w_q(t)。
二根の条件付きsupermartingaleと点法則のBayes公式から
  E^(p)[1_{p境界前 at t}H_ell(t)|F_u]
       <=(1+o(1))1_{p境界前 at u}H_ell(u)、u<=t。           (C10)
補助葉の引退による消滅は上界に有利。
同じ指定外線上の一証人zと二葉を展開すると、相異なる葉は接続r²と正確に一致し、
同じ葉はr²w²<=B r wで払える。全ラベルが指定線を共有しないので単位source価格を使え、
  E^(p)[1_{p境界前,z∈S_t}H_ell(t)²]
       <=C L_ell(L_ell+B)t/n。                             (C11)
一葉版も C L_ell t/n 以下。

活性化時刻s_ell以後、1−r(t)=∫_{s_ell}^t r(u)Lambda_ell(u)du。

が正しい。自己率項を0にしてはいけない。

Iと、各線の葉和へrを掛けた代理危険度の差は
  (rho n)^−1Σ_ell∫1_{p境界前,ell活性}(1−r)H_ell dt
以下である。C12のH/n部分から二重時間積分を作り、C10で未来時刻を過去へ戻す。

自己率B/n部分は活性の単調性と一証人一葉版により

全てT固定を定数へ吸収した加法誤差であり、主log係数を固定倍にしていない。

8. 長線の葉和超過と決定論的残り費用

L_ell>=B log nを長線とする。時刻t、証人z∈ellに対し
  H=r_ell Σ_{q∈ell\{p} active}m_t(q)w_q、D_z(t)=Σ_{q∈ell\{p,z}}m_t(q)。
補助次数kを固定する。異なるk葉のr^kはpとk葉の接続と一致する。
a<k人へ反復した葉はB^{k−a}、候補数L^aで払い、全反復型はC_k B L^{k−1}以下。
従って
  E^(p)[1_{p境界前,z∈S_t}H^k]
   <=(1+o(1))(F_z(t)/n)[D_z(t)^k+C_k B L^{k−1}]。          (C14)
F_z(t)=∫_0^t m_u(z)du。F_z=0なら左辺も0であり、正の投入密度を下から割らない。

epsilon>0を固定し、H1_{H>D+epsilon L}<=H^k/(D+epsilon L)^{k−1}を使う。
D<=Lから主項はL(1+epsilon)^{−(k−1)}以下、反復項はC_{k,epsilon}B以下。
危険度1/nを掛け、証人z、線、時刻へ足す。全体基準はn^{−2}ΣL²=O(log n)。
長線ではB/L<=1/log nなので、実際の信用葉和をDへ替える正部分誤差R_longについて
  limsup_n E^(p)R_long/log n
       <=C epsilon+C(1+epsilon)^{−(k−1)}。                 (C15)
許容epsilon Lの費用は一証人価格からO(epsilon log n)。
同じ過程に対し、epsilonを小さく固定し、次に十分大きい固定kを選び、その後n→∞を取れば
右辺を任意に小さくできる。従ってE R_long=o(log n)。kをn依存で選ぶ必要はない。

zが時刻uに出生したときの決定論的残り費用を
  A_z(u)=n^{−1}∫_u^tau Σ_{q∈ell(p,z)\{p,z}}m_t(q)dt
            <=T L_pz/n
とし、主根境界sigma_pより前に生まれた長線証人についてP_long=Σ_z A_z(出生時刻)。
実際の境界がtauより早くても、残りをtauまで積分するのは非負な上界。
A_z/(T L_pz/n)を出生保持重みとして源階層へ入れる。
各証人の主価格は b_z=n^{−1}∫_0^tau m_u(z)A_z(u)du、M_long=Σ_z b_z。

固定m次展開の証人反復ブロックがr>=2なら、その一出生価格の総和は
  C_r n^{−(r+1)}Σ_{ell∋p}L_ell^{r+1}=O_r(1)。
r=1はO(log n)。従って少なくとも一反復があればlog^mより一つ以上の冪を失う。
異なる証人z1,z2が指定線を共有する例外では、その線はpを通らない。
通ればp,z1の対象線が指定外でなくなるためである。G3から
  Σ_z1 L_pz1 Σ_{z2∈指定線(z1)}L_pz2
       <=C n^{1+xi}Σ_z1 L_pz1=O(n^{3+xi}log n)。
各証人の出生×費用からn^{−2}ずつ付き、例外対はO(n^{−1+xi}log n)。
残る証人をO(log n)ずつで払ってもo(log^m)。複数例外は有限個の証人対のunionで覆う。
一般配置は正確なb_zの積で払えるので
  ||P_long||_{L^m(P^(p))}<=M_long+o(log n)。                (C16)
高次ノルムを主張するのは代理量P_longであり、実際の長線危険度との差はC15のL1誤差として扱う。

9. 短星：反復と全接続例外

短線はL<B log n。活性短線上の葉q、唯一の出生証人zと主根pを星(p,q,z)と呼ぶ。
  X_t=Σ_{短星}m_t(q)r_{ell(p,q)}w_q
を、主根境界後には0とする。短線部分の代理危険度は∫X_t/n dt。
t0=n^{gamma−1}を置く。m次展開の異なる葉数a、異なる証人数jには1<=j<=a<=m。
同じ物理葉は主根との線と証人を一意に定めるので、別証人を持つことはない。
証人と物理葉または主根が一致する項は0。

j<mの場合、各星の最初の葉＋証人はG1よりO(n²log n)通り、
同じ短線へ加える葉はB log n以下、物理葉反復はB^{m−a}。
源価格C_m(t/n)^jを掛けると寄与は
  C_m(n²log n)^j(Blog n)^{a−j}B^{m−a}(t/n)^j。
(tnlog n)^mで割ると
  C_m(B/(nt))^{m−j}(log n)^{a−m}=o(1)                    (C17)
がt>=t0に一様に成立する。B/(nt)<=n^{delta−gamma}を使った。
同じ星の反復m_iに対するr^{m_i}は、異なる葉a_iの接続r^{a_i}以下なので不利な因子を作らない。

j=mならa=m、全星線は異なる。主項から外れる場合を次の全分類で覆う。
(i) 異なる星の二ラベルが指定線を共有する場合。
    一方のラベルを固定し、他方vとその星のもう一つのラベルをG3で数えるとn^{1+xi}。
    この指定線はpの外であり、通常の星行和n²log nに比べn^{−1+xi}の節約。
    葉−葉、葉−証人、証人−証人の全組を含む。
(ii) 葉q_i,q_jの線が長さn^gammaを超える場合。
    q_i固定でそのq_jはG4よりO(n^{2−gamma})人。q_jの星証人はB log n人以下。
    通常の星行和に比べO(B/n^gamma)の節約。
(iii) 葉間線が長さ<=n^gammaで、新しい出生証人により活性の場合。
    証人候補n^gamma、追加価格C_m t/nなので比O(n^{gamma−1})。
(iv) 葉間線が、既存の第三の星証人z_kにより活性の場合。
    k=i,jなら星線が同じになりj=mに反する。
    他のkならpは葉間線の外で、G3のΣ_{z_k∈ell(q_i,q_j)}L_pz_k<=C n^{1+xi}を使う。
    既存のm人の出生価格を保ったまま、通常の一星行和からn^{−1+xi}を節約する。
    他の物理葉やpを証人にする項は0。

これ以外では、各葉間の指定外線は空でr=1、指定線共有もない。
星ごとのrと主根・葉の混合接続が完全に一致する。
複数例外の同時発生は有限個のラベル対・葉対の単独例外unionで覆える。
各単独例外では他の条件を捨てて上から数えるため、例外の積を独立と仮定しない。
接続を外すrho^{−O(m²)}、指定線の固定価格、有限重複型数はC_mに吸収する。

  D_t=n^{−1}Σ_{短い(p,q,z)}m_t(q)F_z(t)
と置くと、一般配置の単位源価格と上の全例外により、固定mに対しt>=t0で
  E^(p)X_t^m<=(1+o(1))D_t^m+epsilon_m(n)(tnlog n)^m、
  epsilon_m(n)→0。                                        (C18)
誤差比はn^{delta−gamma},n^{gamma−1},n^{−1+xi},n^{−zeta}の固定倍で覆える。
実際のmaskを下から割っていない。主項にはm_t(q),F_z(t)をそのまま残し、粗い誤差だけにm<=1を使う。
Minkowskiで
  ||∫_{t0}^tau X_t/n dt||_m<=∫_{t0}^tau D_t/n dt+o(log n)。(C19)
t<t0は一証人・一葉価格でEX_t=O(tnlog n)。早期積分の期待はO(t0²log n)=o(log n)。
ここには証明していない高次ノルムを課さず、L1誤差として分離する。

10. point lawの危険度上側集中

§7の信用除去誤差、§8の長線葉置換誤差、§9の早期短星をR_n>=0に集めるとER_n=o(log n)。
残る非負量Y_n=P_long+∫_{t0}^tau X_t/n dtについて、任意固定mで
  ||Y_n||_m<=M_long+M_short+o(log n)。
長短の区分は線長だけなのでq,z交換に対称。
同じtauで切った全型の場に対し
  M_long+M_short
   <=n^{−2}∫_0^tauΣ_{q,z≠p,q≠z;指定外共線}m_t(q)F_z(t)dt
   =1/(2n²)Σ_{q,z≠p,q≠z;指定外共線}F_tau(q)F_tau(z)=A_n(p)。(C20)
最後は有限積(F_t(q)F_t(z))の微分とq,z交換から厳密に出る1/2である。
別々の型の最終時刻を入れることは許さない。

I_p<=Y_n+R_n。G6とMarkovから、固定epsilon>0、固定mに対し
  limsup_n sup_p P^(p){I_p>(R_p+epsilon)log n}
       <=[M/(M+epsilon/2)]^m
となる有限の固定Mを取れる。R_nはL1 Markovで先に除く。
右辺はmを任意に大きい固定値へ取ることで0。
従って
  sup_p P^(p){I_p>(R_p+epsilon)log n}→0。                 (C21)
極限順序は、各固定m,k,epsilonに対するn→∞、次に要求精度に応じた固定次数の選択である。
n依存次数の源階層や、任意次数に共通の定数を仮定していない。

11. タグの上側最大評価を全方向で閉じる

主根pを通る指定外ell、一つの固定セル・型部分Eについて
  H_ell,E(t)=r_ell(t)Σ_{q∈ell∩E\{p} active}w_q(t)、
  L_ell,E=|ell∩E\{p}|
とする。最初にH_ell,E>L_ell,E+epsilon_0 nとなる時刻と主根境界の小さい方で階層を凍結する。
全葉とpが同じ指定外線上なので、相異なるa葉の接続はr^a、一般単位価格の証人なし量である。
反復をB^{m−a}で払うと、停止時にも
  E^(p)H_ell,E^m<=(1+o(1))L_ell,E^m
                           +C_mΣ_{a=1}^{m−1}B^{m−a}L_ell,E^a。
全方向へMarkovを足す。G4により主項の上界は
  (1+o(1))Σ_{h>=1}C h [2/(2+epsilon_0 h)]^m。             (C22)
m>2で可算和は収束し、m→∞で0。例えば一つのm0>2の可和列で支配して極限を取れる。
反復項の方向和は
  a>2: C_m(B/n)^{m−a},
  a=2: C_m(B/n)^{m−2}log n,
  a=1: C_m n(B/n)^{m−1}。
十分大きい固定mで全て0へ行く。従って、主根pの境界前に、全線・全有限セル・型で
H_ell,E<=L_ell,E+epsilon_0 nが破れる点法則確率はo(1)。

この良事象で、活性化以後の1−r=∫rLambdaは、p以外の信用付きmask和と自己率で
  1−r_ell<=決定論的指定外投入量+C_data T epsilon_0+TB/n。
G5のlambda_cap<1−rhoの固定差より、epsilon_0を十分小さく固定し、その後nを大きくすれば
右辺<1−rho。したがってr=rhoのタグへ到達できない。
全方向数を単にn²倍してしまうと失われる評価を、(C22)のheight和で保持している。
ここでも正の型密度や正のmask下界は不要。

12. 上限信用損失と期待出生数

第一稿(S3)より、上限B到達には I_p>=delta log n−O(1) が必要。
G6のr_*<deltaとC21から、点法則で上限が最初の正境界となる確率は一様o(1)。
§11でタグもo(1)、§6で全体停止もo(1)。
保存信用の密度恒等式により、元の法則でその早期境界に保存される信用の期待は
  E[Z_p(T)1_{早期境界}]=P^(p)(早期境界)=o(1)。           (C23)
これは生の早期境界確率へBを掛けるより強い、点法則による信用損失評価である。

各時刻にEZ_p=1。selected/deadの信用は0、出生可能なactive信用は
1_{t<sigma_global}1_{p∈Q_t}w、正引退または全体停止後は保存値である。
停止後にQのsnapshotを残す実装でも、この出生可能指示を省略しない。
締切tau(p)による保存値はt>tau(p)のmaskが0なので、出生期待の損失を生まない。
それ以外の保存値はC23で一様o(1)。従って
  E|S_T|=n^{−1}∫_0^TΣ_p m_t(p)E[1_{t<sigma_global}1_{p∈Q_t}w_p(t)]dt
        =n^{−1}Σ_pF_T(p)−o(n)
        =(A−o(1))n。                                     (C24)
最初の等式は停止count N_{t∧sigma_global}のcompensator。
sigma_globalを引き起こす最終出生は出力に含み、jumpでは直前状態と<=の予測可能版を使う。
dt積分では<の表示と同じ。点数上限2nにより可積分性もある。
G7の型密度1/4は最後の格子和に入るので、出生率を4倍にする必要はない。

  P(|S_T|>=k)>=[E|S_T|−(k−1)]/[2n−(k−1)]>0
が十分大きいnで成立する。よって|S|>=cnのno-three集合が存在する。

有限証明書を Lean に接続する検証器の仕様
2026-11-08

状態：設計仕様。Lean 実装、幾何soundnessの形式証明、確率的接続定理の形式証明は未完了。
旧C++/Python計算が通ったという事実を公理にする設計では、最終定理の完全形式化にならない。

1. 三つの層を分ける

(A) 探索・データ生成
  既存candidate、空間葉、使用順序、角度分割、候補上界を作る。
  この層はC++/Pythonでもよく、正しさを信頼する対象にしない。

(B) 有限データの検証器と、その健全性定理
  有理数・整数の有限データを検査し、「受理されたなら数学的な有限条件を満たす」
  ことをLeanで証明する。数値実行結果だけでなく、この含意が必要である。

(C) 一般の確率的接続定理
  有限条件とδ<1等から、任意の固定c<Aについて十分大きい全nで合法出力が存在することを
  証明する。BはCを証明しない。Cを仮定に残せば、結果は明示的な条件付き形式化となる。

最終定理は B と C と具体データの受理証明を合成する。
既存の共有幾何backend、その実行ログ、SHAの一致は、Bの健全性定理の代わりにならない。

2. 入力の意味を固定する

入力は少なくとも次の有限データを持つ。
・型Fin4、正の有理数のphase継続時間、各phaseの型と代表セル、使用順序。
・有理矩形上の非負参照密度と、その対称像による全場。
・各phaseのaccepted矩形。実マスクはその対称像unionの内部で1、共通境界で0。
・Γ16、K,λ,ρ,δ、主方向係数D、時間縮小率s。
・risk上界を正当化する有限角度データ、または検証済み幾何アルゴリズムの入力。

有効性条件は、分母の正性、boxの範囲、phaseとatomの対応、順序の一意性、型の範囲、
密度の非負性、s>0等である。各accepted矩形の重複を単純加算してはいけない。
検証器は重複を拒否するか、数学的unionへ正規化するかを明示する。現データとの互換性では
対称像を含めたunion正規化が必要である。

有限時間分割と全空間分割をnより先に定義する。整数格子のnがその分母の倍数であることを
要求しない。偶奇型の格子点数と面積の1/4対応は一般接続側のRiemann和補題で証明する。

3. 必要な有限条件と理想的なsoundness契約

数学的な契約は概ね次の形である（これはコンパイル済Lean宣言ではない）。

  check(data)=true
    ⇒ ValidFiniteSchedule(data)
       ∧ Mass(data)>1501/1000
       ∧ (∀r,x,d∈Γ, L_{d,r}(F_T;x)<K)
       ∧ (∀r,x,d∉Γ, L_{d,r}(F_T;x)<λ)
       ∧ (∀使用型r,使用位置x, R_r(F_{τ_r(x)};x)<δ)
       ∧ 0<ρ ∧ λ<1−ρ ∧ K<2 ∧ δ<1。

Dは自由に小さく選べる入力ではない。今回の固定定義
  D=(Σ_{k=1}^{256}1/k²+1/257+1/(2·257²))^(−1)
との一致を検査し、x^(−2)の凸性・尾部積分からD>1/ζ(2)を別途証明する。
この算術・解析補題も一般接続の必要条件であり、riskを小さくする任意のDを許可しない。

有限checkerに全ての実数x・角度・無限方向を直接列挙させるのではない。
以下の幾何補題で有限検査から全称命題へ渡す。
時刻も全時刻を列挙せず、非負累積場の単調性とphase終端の上界で覆う。

4. 空間・質量・prefixの有限検査

・代表セルの四つの対称像を列挙し、重複像を除く。
・accepted矩形のunionを共通格子または有理矩形の分割へ直す。
  面積を有理数で計算し、Σ_phase duration×area/4 が保存質量と一致することを検査する。
  現在の共通格子32768²を全セル走査する実装に限定する必要はない。
  矩形の端点で分けた区間走査にも、同じunion面積の健全性定理を与えられる。
・各phaseの実マスクが参照マスク以下であることを検査し、累積場の支配を帰納する。
・旧証明書からの継承では、対応するatomと全型・全セルのprefix支配を整数で検査する。
  「旧rowのSHAが一致」のみから幾何上界を仮定しない。
・保存証明書の依存を有限の非循環なグラフとして扱い、最終的には幾何健全性のある葉へ戻す。
  あるいは旧依存を全て展開して単独のデータへ平坦化する。

必要な補題は、有限矩形unionの面積、境界の零測度、対称写像の測度保存、
非負場の単調性、phase終端の累積場、最後の使用時刻、時間短縮補題である。

5. 方向容量の有限化

参照終端場は有限矩形で一定なので、固定原始方向の弦積分は切片の区間ごとに一次式である。
切替切片は格子頂点を通る線で決まり、区間内の最大値は端点から検査できる。
Γ16と高さ4..7について、方向・型対・有限の切替切片を全て覆うことを証明する。
現在の容量検査では8806直線が使われたが、その件数自体は証明の仮定ではない。

高さh≥8では、主座標方向に正方形を通る長さが高々1であることから
  C_d(F_r+F_s)≤||F_r+F_s||∞、
  L_{d,r}≤||F_r+F_s||∞/(2h)≤||F_r+F_s||∞/16
を使える。これにより無限の方向集合を有限なセル最大値へ落とす。
現終端場の128格子が16格子へ厳密に圧縮できる性質も、有理値の一致として検査する。
近似的に一定だという仮定を導入しない。

6. 全角度riskの健全性

現在の各accepted葉は主としてboxとkernel_upperを保存している。単にその有理数が
閾値未満であることをLeanで示しても、「実際の弦積分がその数以下」はまだ証明されない。
選択肢は二つある。

方式I：既存の上界アルゴリズムを数学的に形式化し、有理入力で検証済み実装を実行する。
方式II：生成側に詳細な区間証拠を出力させ、小さい検証器でその証拠を確かめる。
後者では生成側の切替点探索・分割探索を信頼せず、検証側で被覆と枝条件を確認する。

方式IIの一つの具体的なデータ設計は以下である。
・閉根矩形Q、型対、四方向族ごとに 0=u0<...<uJ=1 の有理角度分割。
・各区間で採用する上界 α+β/u と、その由来になる有限のmax/min/正部分の枝情報。
・各枝の大小関係を区間全体で保証する有理端点比較。
・積分のlog項を囲う有限有理級数と、その剰余次数。

先に証明すべき解析補題は以下である。
(i) 矩形階段場の弦を頂点係数κによる正部分の有限和で表せる。
(ii) 閉根矩形内の切片範囲について、既存A2の頂点上界とA3の正の跳び上界が成り立つ。
(iii) それらと||F||∞の最小は、根全体に対する非負上界である。
(iv) 区間上の α+β/u の比較は、u>0を掛けた一次式の端点比較から検証できる。
     これを有限max/minの枝全体へ帰納する。完全な切替点探索器の正しさを証明しなくても、
     提供された分割の全被覆と各枝の正しさを検証すれば足りる。
(v) 0<r<s上で
      ∫(a+b/u)²du=a²(s−r)+2ab log(s/r)+b²(1/r−1/s)。
     log(s/r)はz=(s−r)/(s+r)に対する級数と非負剰余で有理囲いする。
     2abの符号に応じた上下端の選択を証明し、丸め方向を反転させない。
(vi) u=0を含む最初の区間では定数上界を使ってβ=0とする。
     単独の端点が積分を変えないこと、有限上界の可積分性も証明する。
(vii) 方向平均・三つの型対の和・D/6・時間縮小s²を合成してrisk上界を得る。

旧の96bit外向き丸めや512bit中間値をそのままLeanへ移す義務はない。
任意精度整数・有理数でより単純な検証器を作れる。ただしその実装の受理条件から
上記の実数積分上界が従う健全性証明が必要である。
今回δに余裕を持たせたことで、将来この証拠を粗くできる可能性はあるが未実施である。

1. 全て有限・有理数で定義できるデータ

各phase長alpha_i>0とマスク値を有理数とする。phase数J、T=Σalpha_iはnより先に固定。
delta=d0/d1、gamma=c0/c1、zeta=z0/z1は(0,1)の固定有理数。
  B_n=min{b∈Nat: b^{d1}>=n^{d0}},
  G_n=min{b∈Nat: b^{c1}>=n^{c0}},
  E_n=min{b∈Nat: b^{z1}>=n^{z0}}
とする。いずれも正整数であり、n^delta<=B_n<n^delta+1、同様にG_n,E_nを評価できる。
eta床は1−1/E_n、virtual閾値はG_nを使う。
実数冪をtransitionの計算へ入れず、整数の冪比較だけで閾値を定義できる。

固定整数Lを十分大きく選び、各phaseを
  N_n=L n^4 2^{n²}
個のstepへ分割する。phase iのstep長はDelta_i=alpha_i/N_n。
LはT,K,rho,Gammaなど固定データだけに依存させ、以下の有限領域条件がn>=n0で成り立つように取る。
小さいnまで定義を要するなら、条件を満たさないnでは最初からidle treeにしてよい。
最終存在定理はn>=n0だけを使う。

全step数はJ N_n。各nodeからの分岐は「無出生」と各active点qの出生の高々n²+1個。
各phaseのmaskはそのphase内で一定、最後のstepの出生はそのphase内の出生として扱う。
step末尾で期限を迎えた点を正引退させる。

2. 一stepの順序と厳密補償

step直前のactive重みはw_p<=B_n。旧stateの率を
  lambda_q=m(q)w_q/n、Lambda=Σ_q lambda_q
とする。pがこの旧stateで出生qを受けたときの倍率J_p(q)∈{0,1/2,1}を定め、
  h_p=Σ_q lambda_q(1−J_p(q))
とする。active以外の率は0。
0<=h_p<=Lambda<=n B_n<=2n²。
Delta Lambda<=1/2となるnから考える。

(i) active重みを wbar_p=w_p/(1−Delta h_p) にする。
(ii) 旧stateを用いて kbar=k+Delta Lambda_ell/a_N(k)、
     rbar=r(1−Delta Lambda_ell 1_{N_ell=1})、
     etabar_ab=eta_ab(1−Delta kappa_ab) とする。
     既に凍結した座標は変更しない。
(iii) 無出生を確率1−Delta Lambda、出生qを確率Delta lambda_qで選ぶ。
(iv) 出生qの幾何更新を行い、active重みをJ_p(q)wbar_pにする。
     無出生ならJ_p=1。選択・幾何死亡は0、初回指定線は1/2。
(v) 正引退と全体停止の判定を行う。主根の混合階層はpostgeometry/prepositive snapshotを保存。

新しい指定外線の活性化ではr=1のままであり、次のstepからrを減らす。
既にactiveだった線のEuler更新に、新しく生まれた証人の同step効果を二重に入れない。

各active根の保存信用は、出生・無出生のどの分岐でも、(v)が正値を変えないので
  E[Z_p,next | node]
   = wbar_p[(1−Delta Lambda)+Delta Σ_q lambda_q J_p(q)]
   = wbar_p(1−Delta h_p)=w_p。                             (D1)
既に保存・死亡した根も不変。従って全有限treeでEZ_p=1が厳密に成立する。
これはEuler近似による1+o(1)ではない。

3. overshootと、誤差計算に使う領域

wbar_p<=2B_n。境界越えを(v)で保存するため、保存値は2B_n以下。
k,r,etaの一step変化はC n² Delta以下。
従って、active状態だけでなく停止した最後のsnapshotにも、nが十分大きければ
  w<=2B_n<=4n,
  2−k >=(2−K)/2,
  r>=rho/2 （接続因子として必要な線上）,
  eta>=1/2
が成り立つ。
virtual削除質量は出生により大きくjumpする場合があるが、最後の出生の実削除質量は
そのstep直前のvirtual上界G_nで抑えられる。停止後に次の出生を行わないので、
poststateのvirtual overshootを一イベントjump上界へ誤って流用する必要はない。

active重みの正の下界は、C²誤差lemmaの前に次の直接積式で得る。
  −log(1−Delta h_p)=Delta h_p+O(n^4 Delta²),
  log a_N(kbar)−log a_N(k)=Delta Lambda_ell b_N+O(n^4 Delta²)。
N=0から1への半減は a1(kbar)/a0(kbar)=1/2 と厳密に一致する。
全stepを足すと、rootのactive期間に
  log w_p =Σ Delta H_p +Σ Delta lambda_p(1−Σ指定 b_N)
               +Σ指定 log a_N(k)+O(n^4 T Delta_max)。       (D2)
自己項はO(TB_n/n)=o(1)、最後の誤差もo(1)。
よってactive w_p>=2^{−g−1}を、十分大きいnで再び得る。
ここではlog wの微分をw≈0で評価していない。明示した比のlogを使っている。

4. 固定ラベルrational potentialの局所誤差lemma

ラベル全集合Lの大きさをRとして、第一稿のY_C,D=E_L Phi_C,Dを考える。
離散状態を固定し、positive retirementの判定をまだ適用しない各branchでは、
この量は有限個のw,k,r,etaのrational functionである。
指定線のa_N逆冪は (2−k)^{m−1}/(2−N)^{m−1} である。
rootが幾何死亡したbranchでは量全体を0と定義し、N=2でa_Nを割る式を評価しない。
証人出生時のe_qは[0,1]の決定論的係数であり、連続変数へは微分しない。

上の拡大領域では、このpotentialと二階までの偏微分の絶対値はC_R n^R以下で覆える。
座標数はRに依存する固定数である。
更新変位は各必要座標につきC n³ Delta以下。
重み更新は
  wbar−w=Delta w h+O(n^5 Delta²)
で、k,r,eta更新の一次部分は連続稿のvector fieldそのもの。
従って無出生branchについて
  F_0(ybar)=F_0(y)+Delta DF_0(y)b(y)+O_R(n^{R+6}Delta²)。
出生branchqについては一次の粗いLipschitz評価だけでよく、
  F_q(ybar)=F_q(y)+O_R(n^{R+3}Delta)。
出生確率の総和はDelta Lambda<=2n² Deltaなので、このbranch誤差の合計も
O_R(n^{R+5}Delta²)。
従って一stepの条件付き期待は
  E[F_next−F_now | node]
   =Delta {DF_0 b+Σ_q lambda_q(F_q−F_0)}
                        +O_R(n^{R+6}Delta²)                (D3)
となる。

正引退・停止境界はrational functionではないが、上からの評価には次の処理で十分。
非主根の正引退は非負potentialを0へ落とすため(D3)の上界を悪化させない。
主根または全体停止はpostgeometry/prepositiveの値を保存するため、そのbranchのF_qと同じ。
幾何死亡は既にF_q=0で評価した。これで非滑らかな境界へTaylorを使う必要はない。

全stepの二乗長の和は ΣDelta²<=T Delta_max。
従って任意固定Rについて
  epsilon_R(n)=C_R n^{R+6}T Delta_max
は任意の固定A>0に対して o(n^{−A})。
必要な標準的実解析は、有限変数の二階Taylor剰余と、2^{n²}が任意固定冪を支配することだけ。
Rがnと共に増える一様主張はしていない。

5. 混合源帰納の離散版

第一稿§6の連続generatorの既存部分は非正、正源は同稿(S7)である。
(D3)からnodeで
  E[Y_C,D,next | node]
   <=Y_C,D+Delta Σ_{q∈D} beta_q Y_{C∪{q},D\{q}}
                              +C_R n^{R+6}Delta²。          (D4)
一般配置でbeta_q=m(q)e_q/n、その他でbeta_q=max(1,A1)^g m(q)e_q/nを使う。
A1は安全なovershoot域の上界2/(2−K)へ置き換えても固定定数に留まる。
一般配置のbetaにはこの固定倍を入れない。

F_q(j)=Σ_{i<j}Delta_i beta_q(i) とする。
有限積の更新で、
  ∏_q F_q(j+1)−∏_q F_q(j)
     >=Delta_j Σ_q beta_q(j)∏_{r≠q}F_r(j)
が成り立つ。二つ以上の新増分を含む残りの項は全て非負である。
従って|D|による有限帰納で
  E Y_C,D(j)<=∏_{q∈D}F_q(j)+C_R epsilon_R(n)。              (D5)
誤差の再積分係数は有限なΣDelta beta=O_R(1)で抑え、帰納深さはR以下。
必要ならc_RをR+6から大きくして一つのepsilon_Rへ吸収できる。
同時停止した全階層でも、sourceが停止後に0となるだけなので同じ証明。

etaの床は1−1/E_n−O(n²Delta_max)=1−O(n^{−zeta})。
従って一般配置の保存混合量には
  E Phi_C,D(j)
    <=(1+O_R(n^{−zeta}))∏_{q∈D}[Σ_{i<j}Delta_i m_i(q)e_q(i)/n]
                                            +epsilon_R(n)  (D6)
を得る。任意固定ラベルの粗価格はC_R n^{−|D|}+epsilon_R(n)。
有限個またはnの固定冪個のラベル配置へ足しても、epsilon_Rは任意負冪に吸収できる。

6. 点の法則のtransitionは厳密に何か

(D1)により、最終保存信用Z_pを密度とする有限tree上の確率測度を定義できる。
pがactiveのnodeでは、
  P^(p)(出生q | node)=Delta lambda_q J_p(q)/(1−Delta h_p),
  P^(p)(無出生 | node)=(1−Delta Lambda)/(1−Delta h_p)。       (D7)
両式の和は1。正引退後は密度が一定なので元のtransitionへ戻るが、解析対象はその前で止める。
自己出生はJ_p(p)=0で禁止される。しかしh_pや補償中のlambda_pは残る。

連続版のlambda_q J_p(q)と比較した一step確率の差はO(poly(n)Delta²)。
点法則に関する後続の式は、(D7)を使うか(D6)の保存混合量を直接使う。
連続版transitionを厳密同一として使用してはいけない。

二根の条件付き将来評価も(D4)を途中nodeから足して得られる。
主根のactive信用には固定正下界があるので、Bayes公式で割っても誤差はsuperpolynomialのまま。
直線上の葉や有限個の型を足すためのnの固定冪も吸収できる。

7. 指定線を保護する有限tree法則

一本の指定線ellの占有段階内で、ell上の出生を禁止する。
stepの密度倍率は、ell出生なら0、それ以外なら1/(1−Delta Lambda_ell)。
この倍率の元の条件付き期待は1なので、積は厳密なmartingaleである。
保護法則の外部出生確率は Delta lambda_q/(1−Delta Lambda_ell)。
これも連続版の元率と厳密同一ではない。

log密度<=ΣDelta Lambda_ell+CΣ(Delta Lambda_ell)²。
同一占有段階ではkが単調で
  Delta Lambda_ell=a_N(k)(kbar−k)
だから、a_Nの増加性によりこの左Riemann和は∫a_N dk以下。
kのovershootを含めても、log密度<=2log[2/(2−K)]+o(1)。
従って密度はA0²(1+o(1))以下、例えば十分大きいnで2A0²以下。
有限nでも連続版のA0²を誤差なしの上界とは言わない。

c=w/a_Nの保存信用とh(c)=c[1+log(M/c)]の保存entropyを使う。
Mは全snapshotのc上界、例えば8B_nとする。
外部birthの倍率Jについて
  h'(c)c(1−J)+h(Jc)−h(c)=−c[Jlog J−J+1]
は厳密。保護法則の分母とEuler更新による残りは(D3)型のpoly(n)Delta²である。
entropyの0評価は死亡branchで直接h(0)=0と置き、0でTaylor展開しない。
生存・保存した正信用には固定下界があるので、他のbranchの導関数はpoly(n)で覆える。

従って時計集中に使うDoob分解・予測二乗変動は、連続稿の項に全時間epsilon(n)を足したものとなる。
有限martingaleの指数不等式を適用すればよい。連続時間確率積分を新たに導入する必要はない。

8. 危険度主項の時間対称化

step jの危険度は、そのstepより前に生まれた証人だけを使う。
F_j(q)=Σ_{i<j}Delta_i m_i(q)。同じ主根締切までの全stepを使う。
相異なるq,zについて厳密に
  Σ_j Delta_j[m_j(q)F_j(z)+m_j(z)F_j(q)]
   =F_T(q)F_T(z)−Σ_j Delta_j²m_j(q)m_j(z)。                 (D8)
これは有限和の積を、i<j,i>j,i=jへ分けただけである。
同stepの出生は一つなので、最後の対角項が除かれることは自然である。
右の減算項は非負。従ってordered pair和を1/2にする危険度上界は、元の連続場の
1/(2n²)Σ_{q≠z, p,q,z共線}F_T(q)F_T(z)をそのまま上界として使える。
有限phase内の積分Fはsum Delta mと厳密に一致する。

9. 本命候補の数値パラメータ

再認証対象は s=249/250 の時間縮小である。phase長だけs倍、mask値は維持する。
元の場Fに対して新F=sF、投入量Aはs倍、容量はs倍、二次危険度はs²倍。
確率側では
  delta=993/1000、gamma=1993/2000、xi=zeta=1/1000,
  K=255/128、rho=1/8、lambda_cap=4/5
を使う。a0<=256、a1<=128は連続域、最後のEuler snapshotには固定倍の上界を使う。
補助停止の高次評価の例としてm=4096なら
  eta指数 =4−delta−m(1−delta−2xi−zeta)=−13.377,
  virtual最大指数 =3−delta+xi−m(gamma−delta)=−12.328。
両者に離散epsilon_Rを加えてもこのorderは変わらない。
任意固定moment次数の源階層をm=4096に制限しているわけではない。

10. 残る形式化作業と、採用条件

有限tree版の利点は、確率空間・条件付き期待・停止を有限和で定義できること。
ただしtreeが有限であるというだけで、以下の証明が自動的に終わるわけではない。

import Mathlib.Data.Real.Basic
import Mathlib.Data.Finset.Card
import Mathlib.Tactic.Linarith
import Mathlib.Tactic.NormNum
import Mathlib.Tactic.Ring

/-!
A small, kernel-checked prototype for the compensated-process argument.
It proves the algebra of one event and its finite group decomposition.
It does NOT construct the stochastic process, prove a martingale theorem,
or prove a no-three-in-line asymptotic lower bound.
-/

namespace NoThreeLinePreparation

set_option autoImplicit false

abbrev Grid (n : ℕ) := Fin n × Fin n

def orientedArea {n : ℕ} (p q r : Grid n) : ℤ :=
  ((q.1.val : ℤ) - p.1.val) * ((r.2.val : ℤ) - p.2.val) -
    ((q.2.val : ℤ) - p.2.val) * ((r.1.val : ℤ) - p.1.val)

def NoThree {n : ℕ} (s : Finset (Grid n)) : Prop :=
  ∀ p ∈ s, ∀ q ∈ s, ∀ r ∈ s,
    p ≠ q → p ≠ r → q ≠ r → orientedArea p q r ≠ 0

/-- This is the target's definition, not a proof or an assumed axiom. -/
def Target : Prop :=
  ∃ n₀ : ℕ, ∀ n : ℕ, n₀ ≤ n →
    ∃ s : Finset (Grid n), NoThree s ∧ 1501 * n ≤ 1000 * s.card

def groupProduct : List ℝ → ℝ
  | [] => 1
  | j :: js => j * groupProduct js

def totalLoss : List ℝ → ℝ
  | [] => 0
  | j :: js => (1 - j) + totalLoss js

def pairLoss : List ℝ → ℝ
  | [] => 0
  | j :: js => (1 - j) * totalLoss js + pairLoss js

def couplingDefect (js : List ℝ) : ℝ :=
  totalLoss js + groupProduct js - 1

theorem single_credit_compensation (credit rate multiplier : ℝ) :
    credit * rate * (1 - multiplier) + rate * (multiplier * credit - credit) = 0 := by
  ring

theorem defect_cons (j : ℝ) (js : List ℝ) :
    couplingDefect (j :: js) =
      couplingDefect js + (1 - j) * (1 - groupProduct js) := by
  simp only [couplingDefect, totalLoss, groupProduct]
  ring

theorem product_and_defect_bounds (js : List ℝ)
    (h : ∀ j ∈ js, 0 ≤ j ∧ j ≤ 1) :
    (0 ≤ groupProduct js ∧ groupProduct js ≤ 1) ∧
    (0 ≤ couplingDefect js ∧ couplingDefect js ≤ pairLoss js) := by
  induction js with
  | nil => simp [groupProduct, couplingDefect, totalLoss, pairLoss]
  | cons j js ih =>
    have hj := h j (by simp)
    have ht : ∀ k ∈ js, 0 ≤ k ∧ k ≤ 1 := by
      intro k hk
      exact h k (by simp [hk])
    obtain ⟨⟨hp0, hp1⟩, ⟨hd0, hd1⟩⟩ := ih ht
    have hj0 : 0 ≤ 1 - j := by linarith
    have hp' : 0 ≤ 1 - groupProduct js := by linarith
    have hu : 1 - groupProduct js ≤ totalLoss js := by
      unfold couplingDefect at hd0
      linarith
    have hcross := mul_nonneg hj0 hp'
    have hupper := mul_le_mul_of_nonneg_left hu hj0
    constructor
    · constructor
      · exact mul_nonneg hj.1 hp0
      · change j * groupProduct js ≤ 1
        calc
          j * groupProduct js ≤ 1 * 1 := mul_le_mul hj.2 hp1 hp0 (by norm_num)
          _ = 1 := by norm_num
    · rw [defect_cons]
      constructor
      · linarith
      · simp only [pairLoss]
        linarith

theorem coupling_defect_nonnegative (js : List ℝ)
    (h : ∀ j ∈ js, 0 ≤ j ∧ j ≤ 1) : 0 ≤ couplingDefect js :=
  (product_and_defect_bounds js h).2.1

theorem coupling_defect_le_pair_loss (js : List ℝ)
    (h : ∀ j ∈ js, 0 ≤ j ∧ j ≤ 1) : couplingDefect js ≤ pairLoss js :=
  (product_and_defect_bounds js h).2.2

theorem one_group_defect (j : ℝ) : couplingDefect [j] = 0 := by
  simp [couplingDefect, totalLoss, groupProduct]

theorem two_group_defect (j k : ℝ) :
    couplingDefect [j, k] = (1 - j) * (1 - k) := by
  simp [couplingDefect, totalLoss, groupProduct]
  ring

theorem two_slot_first_birth_ratio (k : ℝ) :
    (2 / (2 - k)) / 2 = 1 / (2 - k) := by
  ring

theorem two_slot_derivative_numerator (k : ℝ) :
    2 / (2 - k) ^ 2 =
      (2 / (2 - k)) * (2 / (2 - k) - 1 / (2 - k)) := by
  simp only [div_eq_mul_inv, ← inv_pow]
  ring

theorem finite_event_compensation (credit dt totalRate retainedRate : ℝ)
    (hden : 1 - dt * (totalRate - retainedRate) ≠ 0) :
    (1 - dt * totalRate) * (credit / (1 - dt * (totalRate - retainedRate))) +
      dt * retainedRate * (credit / (1 - dt * (totalRate - retainedRate))) = credit := by
  calc
    _ = (credit / (1 - dt * (totalRate - retainedRate))) *
        (1 - dt * (totalRate - retainedRate)) := by ring
    _ = credit := div_mul_cancel₀ credit hden

theorem scaled_mass_gt_target :
    (249 / 250 : ℚ) * (20228386003019681 / 13421772800000000) > 1501 / 1000 := by
  norm_num

theorem scaled_risk_lt_delta :
    (249 / 250 : ℚ) ^ 2 * (49999 / 50000) < 993 / 1000 := by
  norm_num

end NoThreeLinePreparation
