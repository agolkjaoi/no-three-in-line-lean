1. 容量と一様余裕：契約を補強して採用

非軸では、弦長が切片の連続区分一次関数となるため、格子頂点を通る切片で検査できる。
軸では「開帯ごとの行和・列和」と「境界での0」を別に扱う。
前稿の付録1 §5にある端点検査の一文は、本追補のcapacity章によってこの区別を補う。
実際の既存コードは開帯の和を検査しており、512個の軸値と6個の方向尾部上界を
独立に再計算して保存値との一致を確認した。

また付録1 §3のchecker契約は、点ごとの厳密不等式に留めず、正の有理数κ_H,κ_L,κ_Rを返す。
保存された有限上界・方向尾部から全根に共通の余裕を取り、その値を一般接続定理へ渡す。
これは現在の全上界値を変更する補正ではなく、既存の差を定理の出力として明示する補強である。

2. 固定誤差予算：最終目標に必要な結論へ絞る

保存信用の分解から、有限nで次の厳密な残り投入量公式を取り出せる。
  a_n−E|S_T|/n
   =n^(-2)Σ_p E^(p)[1_{早期正保存}(F_T(p)−F_{theta_p}(p))]。
よって早期保存の点法則確率が一様にε以下なら、E|S_T|/n>=(1−ε)a_n。
粗いTεではなく、実際の投入量a_n εで損失を払える。

ε=10^(-5)、連続質量と1.501の差をΔとすると、格子誤差Δ/4を払っても
目標への残余は約0.00006274457。さらに剪定損失Δ/4を同時に払っても約0.00003682638残る。
二つの費用を同じΔ/4へ重ねて計上していない。

タグ主項の有限和上界は TagBudget.lean の finite_tag_bound として一般に証明・コンパイルした。
無限級数・支配収束を使わず、a=ε_cell/2、m=k+3の変数対応でレビューの式を得る。
一方、局所モーメントの帰納、停止法則、長短星の固定次数評価は残る。
全細格子を使った安全な次数例は非常に大きく、固定次数化が計算速度の改善を意味するわけではない。
この点をbudget章で明示している。

3. 対数なし幾何checker：実装する有力候補

同じ非負上界Uの各枝a+b/uを有理端点上和で囲えば、対数・級数剰余を積分検証から外せる。
元の弦上界と枝の正しさは引き続き証明する必要がある。
枝内の有限望遠和から細分誤差を評価でき、厳密な余裕があれば有限細分で受理できる。
固定精度の丸めを無制限に細分するだけではこの存在保証は得られず、
厳密有理和、または細分後に十分な丸め精度を選ぶ設計を使う。

採用済みの実葉3個で比較した。旧方式の同じUによる積分結果は保存値と完全一致。
新方式ではκ_Rの半分、0.00050192016を残す閾値で3例とも受理できた。
区間数は元の枝数の約1.72〜9.95倍。3例の計測は約4.61秒だった。

第2章 軸容量と一様余裕の修正契約
収録元：capacity_FINITE_CHECKER_CONTRACT_JA.txt

軸・非軸の容量有限化と、一様な正の余裕を返す検証器契約
2026-11-09

対象と結論

本稿は、前世代 certificate_LEAN_CHECKER_SPEC_JA.txt §3,5 の数学的契約を補強する。
前世代ファイル・証明書・過程を変更しない。指摘された軸方向の補足は必要である。
一方、実際の audit_candidate_capacity.py は a==0 の分岐で開帯の行和・列和を検査しており、
軸の境界値だけを検査する実装ではない。独立な整数場復元と有理数計算で全軸最大値が一致した。
一般の幾何有限化を以下に証明し、具体的な正の有理余裕をその結論へ組み込む。
これはLean準備の数学稿と限定した独立算術監査であり、Leanによる健全性の形式証明ではない。

1. 場、境界、弦の正規化

有限有理分割 0=x0<...<xG=1、0=y0<...<yH=1 を固定する。
型rの非負参照場 F_r は開セル (xi,xi+1)×(yj,yj+1) で f_{r,ij}、
正方形外とこの格子の境界で0とする。さらに細かい有限の水平・垂直線集合Bで0にしてもよい。
実場は、accepted矩形の対称像unionの内部から共通境界Bを除いたマスクの累積場である。
各phaseの実場≦参照場という非負支配を先に検査する。

本件の実場のBは32768格子の全水平・垂直線である。
128格子のセル値が各8×8ブロックで同じことを厳密に検査すると、16格子の参照包絡へ圧縮できる。
ここで包絡は、16セル内部にある128/32768格子線の0をセル値で埋めてもよい。
非負性により実場≦包絡が点ごとに保たれる。16格子境界では両者0である。
「128場と16場が境界も含め全点で等しい」とは主張しない。
非軸の弦積分ではこの境界の変更は有限点に限られ、値が等しい。
軸の弦積分では一致しない場合があるため、以下の開帯/境界の分離を使う。

原始整数方向d=(a,b)を符号反転で同一視し h=max(|a|,|b|) とする。
主座標に沿う積分変数tを使う。例えば |a|≥|b|, a>0 なら
  C_d(F;v)=∫_R F(t,(b/a)t+v)dt。
縦主方向では座標を交換する。これは弧長積分ではない。
型を2進偶奇 r∈{0,1,2,3} とし、e_d=(a mod2)+2(b mod2)、s=r xor e_d。
原始方向なのでe_d≠0。必要な二つの無順序型対について
  L_{d,r}(F;v)=C_d(F_r+F_s;v)/(2h)                         (1)
を容量とする。任意の根が決める切片もこの全称vに含まれる。
型対係数1/2と主方向高さ1/hを、弧長による√(a²+b²)へ置き換えない。

2. 非軸有限化の厳密な命題と証明

命題：a b≠0を固定する。C_d(F;v) はvの連続な区分一次関数である。
全切替点は参照分割の格子頂点を通る切片の集合に含まれ、その有限集合上の最大値で全vを覆える。
細かい有限格子線Bを0にする規約でも同じ結論である。

証明：主座標を横へ統一し q=b/a≠0 と書く。
一矩形 (A,B)×(C,D) の弦長は
  [ min(B,max((C-v)/q,(D-v)/q))
     −max(A,min((C-v)/q,(D-v)/q)) ]_+。
これは連続な有限min/max式である。枝が変わる切片は
  C-qA, C-qB, D-qA, D-qB
に含まれる。二つの平行な斜辺式同士は交差せず、端点定数同士も入れ替わらないからである。
これを非負セル値倍して有限加算すれば、全格子頂点の切片で分けた各区間上で一次、かつ連続。
支えの外の二つの半無限区間では0。有限区間上の一次関数は両端の最大以下なので結論を得る。
非軸線は有限個の水平・垂直境界線と有限点でしか交わらず、そこを0にしても積分は同じ。証明終。

現16格子実装との対応：座標を16倍し主方向を正として傾き q=sign·a/h、a>0 と書く。
実装の整数切片zは h y−sign·a x である。全頂点のzは整数であり、
  sign=+1: −16a≤z≤16h、sign=−1: 0≤z≤16(h+a)
の整数全走査は全切替点を覆う。走査する整数の全てが頂点切片である必要はない。
各弦は主座標の整数点と横格子を横切る有理点で分け、区間長×セル値を有理数で足す。
頂点に接する長さ0の交差を含めても積分は変わらない。

3. 軸有限化の厳密な命題と証明

命題：水平方向(1,0)では、各開水平帯 yj<v<yj+1 に対し
  C_(1,0)(F;v)=Σ_i (xi+1−xi) f_ij                         (2)
であり、粗格子境界v=yjでは0である。垂直方向は行列を交換した式。
さらに細かいBを0にした場では、vが追加水平境界と一致すれば0、それ以外では(2)である。
従って全軸容量は「全開帯の値および境界値0」の有限最大値で抑えられる。

証明：vが開帯内かつ追加水平境界外なら、横変数tについて場は各区間でf_ij、
垂直境界の有限点でのみ0だから、積分は(2)。vが0規約の水平境界なら直線全体が0である。
これで全vを尽くす。細格子境界を埋めた粗い参照包絡を使う場合も、(2)は安全側の上界。証明終。

重要：境界での実際の関数値だけでは不十分である。
F=1_(0,1)²なら水平容量の弦は0<v<1で1、v=0,1で0になる。
従って「切替切片の端点を検査」は非軸には適用できるが、軸では
「開帯値を検査する」、または「両片側極限と実際の境界値を検査する」と定義し直す。
軸を角度積分の零測度集合として落としてはいけない。容量は方向ごとの全称条件である。

現実装の a==0, intercept=0,...,15 は、intercept/16 という境界での値ではない。
intercept番目の開帯のセル和を返す。この意味をデータのwitness名にも付ける。
横型対(0,1),(2,3)、縦型対(0,2),(1,3)を全て検査する。

4. 無限方向と時間を有限契約へ含める

主座標で正方形を通る長さは高々1なので、全方向で C_d(F_r+F_s;v)≤||F_r+F_s||∞。
従って h≥8 なら
  L_{d,r}≤||F_r+F_s||∞/(2h)≤||F_r+F_s||∞/16。             (3)
全6型対の有限セル最大を検査すれば、全ての高さ8以上を一括して覆う。
Γ16（高さ3以下）と高さ4..7の全原始方向には§2,3の有限検査を行う。
高さ1の二軸もΓ16に含む。容量上界は終端参照場で確認すれば、非負累積性から全時刻を覆う。
全検査数8806や保存SHAだけを健全性の根拠にはしない。必要なのは方向/型対/切片の被覆である。

5. 一様余裕を返す修正契約

checkerは、有効な有限scheduleと境界規約に加えて、次の非負有理上界を返す。
  U_H: Γ容量の全開帯・切片有限最大。
  U_L: 指定外高さ4..7の有限最大と全高さ8以上の(3)の最大。
  U_R: 全使用領域の閉箱危険度上界を一括して覆う有理数。
U_Rには、各箱の上界そのものの最大、または全箱の受理閾値を使ってよい。
各箱の縮小前実危険度を上から覆う数学的健全性・全箱被覆・継承prefix支配は別途検査済みであることを要する。
使用しない未解決箱を採用質量や使用領域へ直接足してはならない。

時間縮小s>0を適用するなら、容量はs倍、危険度はs²倍になる。
補助出力を
  κ_H=K−s U_H、κ_L=λ−s U_L、κ_R=δ−s² U_R
と定義し、それぞれ正であることを有理数比較で検査する。
受理の健全性定理は、全r・全根・全方向・全使用時刻について直接
  L_Γ≤K−κ_H、 L_Γ外≤λ−κ_L、 R_used≤δ−κ_R                (4)
を結論する。加えて 0<ρ、λ<1−ρ、0<K<2、δ<1 等の別の入力条件を検査する。
κは有限schedule・証明書・パラメータにだけ依存し、整数盤nや根/方向に依存しない。

ここでは「点ごとにR<δだから一様κがある」と推論していない。
閉箱上界/有限容量最大/無限方向尾部を同じ有理Uで覆い、そのUと目標閾値の差を出力する。
縮小前の各閉箱U_j<τという受理なら、新実risk≤s² max_j U_j<s²τ=δ−κ_R であり、
安全にU_R=τを使える。ここでκ_R=δ−s²τ>0を検査する。縮小前のτを新riskと直接比較しない。
空使用領域は別の自明分岐にしてよいが、本件は正質量で非空。
共通格子境界は全phaseで0なので、そこに後から別の使用根や締切を追加しない。

1. 有限 n における保存信用の正確な残り投入量公式

仮定を固定する。n>=2、有限格子 V_n、初期 S=空、固定 T、決定論的可測 mask
0<=m_t(p)<=1 があり、F_t(p)=∫_0^t m_u(p)du と置く。最後の使用時刻 tau_p は
m_t(p)=0 for t>tau_p を満たす。一度も使わない点は tau_p=0 とする。
各 p に、Core の有界非負 martingale Z_p、EZ_p(t)=1 があると仮定する。
出生可能信用 C_p(t)=1_{t<sigma_global}1_{p active}w_p(t) と保存信用 V_p(t) は
Z_p(t)=C_p(t)+V_p(t) を満たす。正の信用は一度だけ保存され、その後不変。
選択・幾何死亡が先なら信用0。出力出生数の compensator は
  E|S_T|=(1/n) Σ_p∫_0^T m_t(p) E C_p(t)dt。                 (1)
以上は有限 n の仮定であり、停止確率の小ささを仮定していない。

theta_p を最初の正保存時刻とする。保存を受けず死亡した場合は便宜上 T と置く。
「早期正保存」B_p は、cap、tag、全体停止による正保存が tau_p より厳密に前に
起こる事象とする。締切での保存は含めない。複数理由が同時なら決定論的に分類してよい。
点の法則は dP^(p)/dP=Z_p(T)。EZ_p(T)=1 なので確率測度である。
  a_n=(1/n²)Σ_p F_T(p)
と置けば、正確に
  a_n−E|S_T|/n
   =(1/n²)Σ_p E^(p)[1_{B_p}(F_T(p)−F_{theta_p}(p))]。     (2)
従って任意の eps>=0 について
  sup_p P^(p)(B_p)<=eps
  => E|S_T|/n >= a_n−(1/n²)Σ_p F_T(p)P^(p)(B_p)
               >=(1−eps)a_n。                           (3)

証明。EZ_p(t)=1 と Z=C+V を (1) に入れる。保存が起きた経路では
V_p(t)=Z_p(T)1_{theta_p<=t}。非負 Tonelli により、時間積分は
Z_p(T)[F_T(p)−F_{theta_p}(p)] となる。締切で保存した場合は角括弧が0であり、
死後の便宜的 theta=T でも0。点の法則の密度公式を使えば (2)。最後は
0<=F_T−F_theta<=F_T だけで (3) が従う。独立性は使わない。

停止境界の規約。sigma_global を引き起こす最後の出生も出力に数える。
jump/count 側は N_{t∧sigma_global} と、直前状態に対する予測可能な <= 指示を使う。
dt 積分の < 指示との差は各経路一時刻だけである。幾何死亡と正保存が同時なら
postgeometry/prepositive の規約で0を先に処理し、正値を架空に保存しない。
締切との同時保存、終端 T での停止は残り mask が0なので追加損失0。
unused の tau=0、V=1 も F_T=0 だから損失0。全体停止が0時刻で起きる場合にも (2) は正しい。
先行死亡の経路は Z_p(T)=0 なので点の法則で零集合。この事実を事前独立性へ置き換えない。

この補題が改善するのは、T eps ではなく a_n eps で損失を払える点と、
最終結論に「全 eps へ確率が消える」という量化を要求しなくてよい点である。

6. 同じ時間軸における単調剪定

固定有限 mask f_{r,t}(x) に対し、別の固定有限 mask が
  0<=f_tilde_{r,t}(x)<=f_{r,t}(x)
を全型・時刻・位置で満たすとする。削除した phase は同じ時間軸上の0区間とし、

新使用点での期限は tau_tilde_r(x)<=tau_r(x)。新主根の同じ期限で全型を切ると
  F_tilde_{s,tau_tilde_r(x)}
      <=F_{s,tau_tilde_r(x)}<=F_{s,tau_r(x)}   for every s。
弦積分、非負重み和、その平方積分は単調なので、新容量・危険度は旧証明の上界以下。
新使用点は旧使用点でもある。型ごとに別々の古い終端を混ぜてはいない。
旧共通境界上を0のまま保ち、必要な新境界も0にする。境界で不等式を破る再定義はしない。

質量損失は
  P_actual=(1/4)Σ_r∫_{[0,1]^2}∫_0^T(f−f_tilde)dt dx。
これは差の実 union 面積によって計算する。対称像や重複葉を多重計上した削除和は
安全な上界にはなるが、実損失との等号を主張しない。
P_actual<=Delta/4 なら §2 の同時予算が使える。今回この条件を満たす具体剪定は未実施。

注意：決定論的場の単調性は、別々の補償過程の早期停止確率の単調性ではない。
旧 P^(p)(B_p) の数値を新過程へ結合なしで継承できない。新しい固定入力に Core/Risk の
同じ一般評価を再適用する。容量・危険度の余裕は維持し、同じ T、同じ安全 C_data を使える
剪定なら本稿の次数選択も安全に再利用できる。分割数を増やすなら C_data と e を更新する。
マスクを n ごとに変える最適化は本稿の固定入力仮定の外である。

  U(u)=min(U1(u),U2(u),M),  0<u≤1
を使う。したがって任意の根 x∈Q について 0≤c_F(x,u)≤U(u)≤M。
場・密度・根座標が有理数であり、有限式木の枝検査が成立する場合、有限有理分割
  0=t0<t1<...<tB=1
と有理数 a_j,b_j により各開区間 (t_j,t_{j+1}) 上で
  U(u)=V_j(u)=a_j+b_j/u
と表せる。枝の正しさは C05 の式木全体の比較で検証する。
具体的には (a-a')u+(b-b') の二端点符号を調べる。u=0でもこの一次式の比較は有効である。
単に最終枝の係数を受け取っただけでは、元の幾何上界との同一性を証明したことにならない。

最初の枝では b_0=0 を要求する。0≤V_0≤M が (0,t1) 全体で成立すれば、
b_0>0 なら u→0 で上に発散し、b_0<0 なら負になるため、実際 b_0=0 が必要である。
最初の区間の積分用値は V_0(0)=a_0 と延長する。幾何上界の U(0)=M とは区別する。
単点0の値は積分を変えず、軸方向容量検査をこの事実で省略してよいわけではない。

正の枝境界では V_j の両端点への連続延長値を使う。現在の U は有限max/minからなり
(0,1]で連続なので隣接枝の端点値も一致する。一般の上界枝を使って端点に跳びがある場合でも、
各枝の一方向極限を別々に使えばよい。有限個の境界点は積分を変えない。
各区間の非負性は端点非負性からも検証できる。以下は枝境界を必ず分割点に含める。

2. 一区間の有理上和・下和 [LF2]

0<r<s、V(u)=a+b/u≥0 とする。u↦1/u は減少するので、b≥0ならVは減少、
b≤0ならVは増加する。非負数上の二乗は順序を保つから V²も同じ向きに単調である。
よって区間全体で
  min(V(r)²,V(s)²) ≤ V(u)² ≤ max(V(r)²,V(s)²。
積分の単調性と定数の積分により
  L(r,s):=(s-r)min(V(r)²,V(s)²)
       ≤ ∫_r^s V(u)²du
       ≤ H(r,s):=(s-r)max(V(r)²,V(s)²)。                 (LF2.1)
全ての端点・係数が有理数なので L,H は有理数である。
最初の枝は b=0 のため、r=0でも L=H=a²s と定め、1/0を評価しない。
ここで使う解析は有界区分連続関数の可積分性・積分の単調性・定数積分だけであり、
log、級数、Vの微分公式を必要としない。

枝 [r,s] を r=v0<...<vN=s と有理細分し、各小区間の L,H を足して L_P,H_P とする。
各小区間で (LF2.1) を適用し有限加法性を使うと
  L_P ≤ ∫_r^s V² ≤ H_P。
さらに小区間幅をすべて h 以下とすれば
  H_P-L_P
   = Σ_i (v_{i+1}-v_i)|V(v_{i+1})²-V(v_i)²|
   ≤ h Σ_i |V(v_{i+1})²-V(v_i)²|
   = h |V(s)²-V(r)²|。                                  (LF2.2)
最後はV²の単調性による有限望遠和である。全変動の一般理論をLeanへ輸入する必要はない。

全枝について
  W=Σ_j |V_j(t_{j+1})²-V_j(t_j)²|
と定めれば W は有限非負有理数であり、0≤V_j≤Mから W≤B M²。
全枝を細分して最大幅 h とした全上和H・下和Lについて
  0≤H-∫_0^1 U²≤H-L≤hW。                                (LF2.3)
枝境界の跳びがある場合でも式は成立する。各枝内の望遠和しか用いていないからである。

枝0を抽出せず [0,η] を粗いMで払う方式も安全である。その区間の上界はM²η、
本当の積分との差は高々M²η。残り (η,1] には上記を適用する。
ηを小さくし、その後正区間を細分すれば余分な量を任意に小さくできる。
ただしηの後ろに来る元の枝境界を全部保持し、上界関数が切り替わる区間を一つに潰してはならない。

3. 有限幅の固定点和と、その誤差 [LF3]

任意精度有理数で各Hを足すだけでも健全だが、分母の最小公倍数が大きくなり得る。
そこで正整数Sを共通分母にし、小区間ごとに
  l_i=floor(S L_i),  h_i=ceil(S H_i)
とする。全下端L^-=(Σ l_i)/S、上端H^+=(Σ h_i)/Sについて
  L^-≤∫U²≤H^+,
  0≤H^+-H<N/S,
  0≤(H^+-L^-)-(H-L)<2N/S                               (LF3.1)
が成立する（N=小区間数、整数値のとき非厳密≤でも十分）。
証明は各floor/ceilでの誤差が1/S未満であることを有限和するだけである。
任意精度整数を使えばoverflowの仮定は不要。有限幅実装ならすべての中間演算の幅を別に証明する。

固定Sのまま無限に細分して受理を保証することは主張しない。N/Sという丸め誤差が増えるためである。
存在証明ではまず有限細分を決め、そのNに対して十分大きい2の冪Sを選べばよい。
今回の実測ではS=2^64を固定したが、これは観測した有限サイズで十分だったという意味である。

4. 四方向・三型と、厳密余裕からの有限受理 [LF4]

型rに対する三つの場 F_r+F_s (s≠r)、それぞれ四方向族、合計12個のU_ellを使う。
スケール前の場の U を抽出し、時間縮小s0=249/250を最後に適用する場合のrisk上界は
  R ≤ w I,  I=Σ_{ell=1}^{12}∫_0^1 U_ell(u)²du,
  w=(D s0²)/24>0。                                       (LF4.1)
D/6 と四方向平均1/4を合わせた24であり、12方向分をもう一度平均してはならない。
各族の上和を足したH,H^+について R≤wH≤wH^+。
全族の枝内変動和をW、総小区間数をNとすれば
  wH^+ ≤ wI + w h W + w N/S。                            (LF4.2)

有限受理定理：有理閾値bに対して、同じ幾何上界Uの積分が wI≤B0<b を満たすとする。
このとき全枝を有理有限細分し、必要なら固定点精度Sも増やすことで wH^+<b を受理できる。
証明：ε=b-B0>0。W=0なら細分誤差は0。それ以外は h<ε/(2wW) とする。
例えば各元枝を同じ2^k個に等分すれば最大幅h≤2^-kとなり、有限のkで条件を満たす。
その有限個数Nについて S>2wN/ε となる2の冪を選ぶ。(LF4.2)から wH^+<B0+ε=b。
丸めない厳密有理和ではS選択は不要である。η方式を使うなら最初に wΣM_ell²η<ε/3
を確保し、残る細分・丸めに各ε/3を配れば同じ結論になる。証明終。

凍結証明書との接続：保存された各葉の kernel_upper を K_Q とする。
その値が幾何算法の健全性によって同じUの四方向平均の三型和を覆う、という既存の依存を引き継ぐ。
すると I≤4K_Q である。採用済みの有理検査が
  (D/6)K_Q < 49999/50000
を与えるので、時間縮小後
  wI < (249/250)²(49999/50000)
      =3099987999/3125000000 =0.99199615968。
新δ=993/1000との差
  κ=3137001/3125000000 =0.00100384032 >0
は全葉共通である。したがって同じUの対数なし証明書が有限細分で存在する。
継承葉では旧参照prefixのUを保持して支配関係を使うことができ、新prefixでの再計算は必須ではない。
全採用葉は有限個なので、各葉で存在する有限分割を集めた全体証明書も有限である。
この存在証明は全体ファイルサイズ・所要時間の実用的上界を与えるものではない。

一様余裕の契約も区別する。δ未満で停止するだけなら、新上和の余裕は δ-wH^+ であり、
旧κをそのまま維持できたことにはならない。全葉有限なのでその最小値は正だが、
明示した一定余裕を返す設計なら、たとえば b=δ-κ/2 を受理閾値とし κ_new=κ/2 を返す。
上の有限受理定理はこのbにも適用できる。既存κを同じ数値のまま維持することは本稿の要求ではない。
確率側の接続がκの特定値を使うなら、その数値を更新してから接続する必要がある。

6. §5「出生だけを有限回生成する核」案の短い評価

連続時間を保った有限回のkernel合成は構成部を軽くする候補である。各点が高々一度出生するなら、
高々n²回の実出生と終端吸収により、合成回数は有限にできる。出生なしflowに沿う総率Λについて
生存関数 exp(-∫Λ) と出生密度 exp(-∫Λ)λ_q の全質量が1である、という一次元恒等式が核の出発点になる。
ただしこれは有限確率空間化ではない。出生時刻は連続であり、履歴からflow・guard・率への共同可測性、
履歴長に応じた状態空間、終端吸収、自然filtration、予測可能な試験関数に対する補償公式は残る。
optional stopping・点/保護法則・Freedmanを自動で省略できるわけではない。
現Poisson構成との同値性か、主証明が使う確率恒等式を直接再証明する必要がある。
本稿では設計評価だけに留め、kernel構成・ライブラリ適合性確認・既存橋の差替えは行っていない。

noncomputable def step (a h : ℝ) : ℝ :=
  1 / (1 + a * (h - 1)) - 1 / (1 + a * h)

theorem cubic_step (a h : ℝ) (ha : 0 < a) (hh : 1 ≤ h) :
    h * (1 / (1 + a * h)) ^ 3 ≤ (1 / a ^ 2) * step a h := by
  have hx : 0 < 1 + a * h := by nlinarith
  have hy : 0 < 1 + a * (h - 1) := by nlinarith
  have hb : 0 ≤ 1 / (1 + a * h) := by positivity
  have heq : (1 / (1 + a * h)) * (1 + a * h) = 1 := by
    exact one_div_mul_cancel (ne_of_gt hx)
  have hh1 : h * (1 / (1 + a * h)) ≤ 1 / a := by
    apply (le_div_iff₀ ha).2
    nlinarith
  have hd : step a h = a * (1 / ((1 + a * (h - 1)) * (1 + a * h))) := by
    unfold step
    field_simp
    ring
  have hden : (1 + a * (h - 1)) * (1 + a * h) ≤ (1 + a * h) ^ 2 := by
    nlinarith
  have hr := one_div_le_one_div_of_le (mul_pos hy hx) hden
  have hs : (1 / (1 + a * h)) ^ 2 ≤ (1 / a) * step a h := by
    rw [hd]
    have hc : (1 / a) * (a * (1 / ((1 + a * (h - 1)) * (1 + a * h)))) =
        1 / ((1 + a * (h - 1)) * (1 + a * h)) := by
      field_simp
    rw [hc]
    simpa only [div_pow, one_pow] using hr
  calc
    h * (1 / (1 + a * h)) ^ 3 =
        (h * (1 / (1 + a * h))) * (1 / (1 + a * h)) ^ 2 := by ring
    _ ≤ (1 / a) * (1 / (1 + a * h)) ^ 2 :=
      mul_le_mul_of_nonneg_right hh1 (sq_nonneg _)
    _ ≤ (1 / a) * ((1 / a) * step a h) :=
      mul_le_mul_of_nonneg_left hs (by positivity)
    _ = (1 / a ^ 2) * step a h := by ring

theorem powered_step (a h : ℝ) (ha : 0 < a) (hh : 1 ≤ h) (k : ℕ) :
    4 * h * (1 / (1 + a * h)) ^ (k + 3) ≤
      (4 / a ^ 2) * (1 / (1 + a)) ^ k * step a h := by
  have hx : 0 < 1 + a * h := by nlinarith
  have hbase := cubic_step a h ha hh
  have hb : 0 ≤ 1 / (1 + a * h) := by positivity
  have hq : 1 / (1 + a * h) ≤ 1 / (1 + a) :=
    one_div_le_one_div_of_le (by linarith) (by nlinarith)
  have hp := pow_le_pow_left₀ hb hq k
  have hpos : 0 ≤ h * (1 / (1 + a * h)) ^ 3 := by positivity
  have hmul := mul_le_mul hp hbase hpos (by positivity : 0 ≤ (1 / (1 + a)) ^ k)
  have hfour := mul_le_mul_of_nonneg_left hmul (by norm_num : (0 : ℝ) ≤ 4)
  calc
    4 * h * (1 / (1 + a * h)) ^ (k + 3) =
      4 * ((1 / (1 + a * h)) ^ k * (h * (1 / (1 + a * h)) ^ 3)) := by
        rw [pow_add]
        ring
    _ ≤ 4 * ((1 / (1 + a)) ^ k * ((1 / a ^ 2) * step a h)) := hfour
    _ = (4 / a ^ 2) * (1 / (1 + a)) ^ k * step a h := by ring

theorem step_sum (a : ℝ) (N : ℕ) :
    (∑ i ∈ Finset.range N, step a ((i : ℝ) + 1)) = 1 - 1 / (1 + a * N) := by
  induction N with
  | zero => simp
  | succ N ih =>
    rw [Finset.sum_range_succ, ih]
    simp only [step, Nat.cast_add, Nat.cast_one]
    ring

theorem finite_tag_bound (a : ℝ) (ha : 0 < a) (N k : ℕ) :
    (∑ i ∈ Finset.range N,
      4 * ((i : ℝ) + 1) * (1 / (1 + a * ((i : ℝ) + 1))) ^ (k + 3)) ≤
      (4 / a ^ 2) * (1 / (1 + a)) ^ k := by
  have hc : 0 ≤ (4 / a ^ 2) * (1 / (1 + a)) ^ k := by positivity
  have hs := Finset.sum_le_sum (s := Finset.range N)
    (fun i _ => powered_step a ((i : ℝ) + 1) ha (by have := Nat.cast_nonneg (α := ℝ) i; linarith) k)
  calc
    _ ≤ ∑ i ∈ Finset.range N,
      ((4 / a ^ 2) * (1 / (1 + a)) ^ k) * step a ((i : ℝ) + 1) := hs
    _ = ((4 / a ^ 2) * (1 / (1 + a)) ^ k) * (1 - 1 / (1 + a * N)) := by
      rw [← Finset.mul_sum, step_sum]
    _ ≤ ((4 / a ^ 2) * (1 / (1 + a)) ^ k) * 1 := by
      apply mul_le_mul_of_nonneg_left _ hc
      have : 0 ≤ 1 / (1 + a * N) := by positivity
      linarith
    _ = _ := mul_one _
