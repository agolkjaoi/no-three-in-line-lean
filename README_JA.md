**最終的な1.501n下界定理は未証明です。** 完成済みの局所・条件付き定理、具体入力の一部、再現手順を公開するための固定スナップショットです。著者名は付けません。

## 人間向けの英語稿

[31ページの英語PDF](docs/paper/output/pdf/no_three_in_line_proof_draft_en.pdf)で、構成・保存された重みの恒等式・幾何と確率の議論・数値検証の条件を、Leanを読まずに追えます。[LaTeXソース・有理数の検算スクリプト・読み方](docs/paper/README.md)も収録しています。

具体的な1.501nへの適用は、全幾何入力の検証・フェーズの対応・質量・各根の期限での直線対予算を条件にしています。無条件の下界証明が完成したという主張や、新たな独立検証ではありません。著者名なし・AI使用明記の研究稿です。

## 形式化の現在地

目標は、十分大きいすべての整数nについて、n×n整数格子から3点共線を含まない集合Sを選び、`1501*n ≤ 1000*S.card`を満たすことです。[Target.lean](NoThreeLine/Target.lean)で定義しています。

2026年11月10日00:22 JSTの監査記録を基準に、ソースとコンパイル記録が一致し、依存先も同梱できる **3,242モジュール**を収録しています。作業中・未検証の33モジュールは完成済みコードとして含めていません。この比率は最終定理の完成率ではありません。

初版から94モジュールを追加しました。[一フェーズの集中評価](NoThreeLine/ProtectedCellOnePhasePowerTail.lean)、[時計停止の評価](NoThreeLine/FrozenClockCauseSmall.lean)、[五原因からの条件付き1.501n出力](NoThreeLine/FrozenFiveCauseOutput.lean)まで進んでいます。低高さの数値行は99/112に増えました。一方、全幾何証明書・入力一致・実際の質量と直線対予算を満たす入力の完成は残っています。[変更履歴](CHANGELOG.md)と[現在地](STATUS.md)に範囲を記載しています。
